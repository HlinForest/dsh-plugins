# 插件使用说明 · 0.16.3-beta.18

## 点选器件填写要求

1. 打开当前项目的“原理图 → 图纸”，点击器件，核对位号和当前参数。
2. 在意见输入区填写所需参数、型号或功能要求；例如说明要达到的亮度、电流或滤波效果。参数有明确要求可以直接填写，只有功能要求时需要对应规格书和工作条件支持推导。
3. 保存评审记录，再“采用意见”。保存本身不改图纸；采用后受影响的步骤会标为待更新。
4. 重新生成相关步骤，核对前后器件、参数、连线及 PCB 的变化，确认意见已落实后记录复核结论。

模型不应把不确定的取值写成已证实参数。修改型号、引脚或封装时，BOM、PCB 和交付检查需要更新。当前原理图可编辑，评审意见、每次执行与接受/待修改结论均保留记录。

## 当前整板复测

本轮使用已安装插件和 DeepSeek 真实模型，对完整 27 器件显示板重新布局布线。实际指标和原生文件见 Demo 与《实际前后核验.json》。没有输入 AD 整板固定坐标、外部完整逐脚网表或直接覆盖为 AD 阻容值。

同一接收器和回流域的滤波器按实际焊盘顺序联合摆放；无法成组时继续普通布局优化。未接通的较短候选需实际修复，最终核验全部信号、铜形、原理图一致性与布线质量后才能替换当前结果。此能力有搜索预算，无法保证任意新板一次成功。

## 需要安装什么

- Windows、Node.js 22+、已初始化并登录模型的 DeepSeek Harness。
- 生成原理图和 PCB 需要 KiCad CLI、配套 Python 和 KiCad 元件库；插件不会把 KiCad 内置在安装包里。
- 自动布线使用 Freerouting；需对应 Java 运行时，联合布局还需插件环境检查列出的 Python 依赖。
- 关键器件规格书、封装资料由工程师通过界面单独上传，不嵌入插件。

先打开“环境与安装”查看实际检查结果。未安装 KiCad 时，可按插件内网部署说明使用 ReviewOnly 模式保存需求、资料和评审；要生成图纸，需由部署方提供 KiCad 安装或解压目录，并配置 CLI/Python/元件库路径。内网需提前准备安装包和依赖，安装器不会自动联网下载或调用模型。

## 工程文件

下载 Demo 与工程压缩包，解压后用 KiCad 打开 editable-project/Circuit.kicad_pro。原理图、PCB、封装库、PDF/SVG 和评审记录均可查看。请以本轮 SHA-256、原生 DRC 和逐项对照为准；仍未确定的 9 只电阻及 2 组电容不因布线通过而获得电气性能批准。
