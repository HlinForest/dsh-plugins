# 显示板：文字评审与修改

在第四步“图纸”点击器件或位号，即可查看当前参数并填写要求；支持多选和按位号选择。

不需要先在聊天中报齐所有位号。可以在图上选中一个或多个器件，再用一句话描述期望值或工作要求。例如：“所选电容改为 4.7 µF，核对耐压与封装，其余器件保持”；不知道具体值时可以描述目标电流、纹波或响应要求。这里的示例不会自动提交到当前工程。

- 修改参数、型号或接法：填写具体期望值，或写明电流、亮度、频率等工作要求。点击“按要求生成修改”会保存评审并回到器件推导步骤；先核对并确认新方案，再重新生成原理图、BOM 和 PCB。
- 只改图面或布线：选择相应修改类型，保留电路参数和接法，重新排布或布线。
- 只需记下问题：点击“只保存意见”，不会生成或改动图纸。

填写的原话、选中器件、当前值、针对的图纸版本、每次执行以及人工复核结论都可追溯。仍缺依据的参数不会因一次生成或 DRC 通过而自动变成已确认。

本轮布局改进使用实际网络和铜形做搜索，不把鼠标点击位置或参考板位置当作布局输入。既有固定机械要求、安装面、铜层、禁止过孔与供电距离继续生效。

## 运行条件

重新生成需要 Harness、本插件、可访问模型、KiCad 完整程序与库、配置的 Python 依赖和 Java。Freerouting 已随 TGZ 提供。工程师电脑暂未安装 KiCad 时可查看 Demo、已有 PDF/图纸，并用 ReviewOnly 模式记录意见；生成和 ERC/DRC 需补齐本机工具，当前没有自动远程 CAD 服务器。

外部规格书与测量 PDF 由使用者单独上传，未内置到插件。当前封装来源包括工程测量资料，厂家公差、采购身份及实物装配仍需核实。

同一项目再次生成时，输入和约束完全匹配的既有生成候选会用当前原理图、封装与规则重新检查，再与新结果比较。保留既有候选时会显示来源，不会把其坐标变成固定位置要求。参数、封装或工艺变化时不沿用不兼容候选。

若工具超时或原生程序退出，意见及失败尝试仍保留。完整候选会先保存为检查点，下一次运行重新核验；只有整轮完成并通过实际连通和布线质量验收的结果才用于交付。人工取消有独立提示，不会被当成超时。
