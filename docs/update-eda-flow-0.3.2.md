# 电路设计 0.3.2：确认与任务启动修复

适用于已经安装“原理图与 PCB／电路设计”的电脑。直接使用原 profile 的项目、模型、登录和窗口运行时；不需要填写工作目录。

在原仓库目录打开 PowerShell：

```powershell
git pull --ff-only origin main
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\update-eda-flow.ps1 -Profile desktop
```

若使用其他 profile，将 `desktop` 替换为原值。脚本自动备份旧插件和配置，用带 SHA-256 的新安装路径更新，恢复原配置。备份位于 `%USERPROFILE%\.dsh\plugin-upgrade-backups`。自定义配置目录可传 `-DshHomePath`，自定义 Harness CLI 可传 `-DshCommand`；缺少离线依赖时可传 `-Registry` 指定内网 npm 源。

安装成功会打印 `Installed EDA Flow 0.3.2`。在方便时重新加载电路设计插件，或正常退出并重新打开 Harness；脚本不会中断聊天。页面左下角显示插件版本，可检查正在运行的是 0.3.2。

## 本次修复

- 确认后的校验未通过时，留在当前步骤并显示具体原因，不再跳到一个无法执行的下一步。
- 文件校验按路径和内容 SHA-256 判断变化，文件大小取自同一次读取；清单顺序或独立大小元数据变化不会单独撤销确认。实际内容变化仍会阻止继续。
- “整理输入”立即显示启动状态；前置条件不满足直接返回原因；异步失败在中间工作区显示，缩小窗口也能看见。
- 旧的轮询响应不会覆盖刚保存、确认后的状态。
- 操作记录保留校验失败的文件名与新增、缺失、变化类型，不再统一称为“上游输入已修改”。

本机使用模拟模型验证流程。内网首次校验失效的具体文件仍需实际运行记录确认；本次修复不把这一未取得的证据当成已定位的环境原因。

## 更新后验证

1. 新建项目，选择“使用显示板输入”。
2. 第一步点击“确认并继续”，成功后左侧第一步应保持已确认。
3. 第二步点击“整理输入”，查看实际进度；成功后再点击“确认并继续”。
4. 若仍提示文件校验问题，在“操作记录”查看“结果需要重新确认”，导出记录即可定位到文件差异。无需自行查找工作目录。

也可下载 [0.3.2 Release](https://github.com/HlinForest/dsh-plugins/releases/tag/eda-flow-v0.3.2) 的 `EDA_Flow_Update_0.3.2.zip`，解压后在包目录执行同一个更新命令。此包用于已有安装升级，沿用原来的 KiCad、Python 和独立窗口运行时。首次安装仍可使用完整 0.3.1 离线包，再执行本次更新。
