# 电路设计 0.4.2：实时进度与输出截断恢复

模型执行时，主工作区现在持续显示当前动作：等待模型响应、收到思考活动、接收回复、KiCad 工具执行、检查导出或回复恢复。状态栏显示已用时间、本次请求轮次、本轮已收到的回复字符数、已完成的 KiCad 操作次数和最近活动，窄窗口不需要展开 AI 助手。助手对话也使用同一提示。

计数来自实际收到的事件；不估算完成百分比，不把页面计时器当作模型活动。45 秒没有新活动时明确提示仍在等待；状态连接失败时另行提示无法确认最新进展，自动重连。刷新页面仍可查看同一任务，可直接在状态栏取消。

第四步输出截断的处理：每轮请求上限仍为 24,000 token，要求模型按小批次定义符号、放置器件和导线。`precise_apply` 是按符号名或对象 ID 替换单个完整对象，不要求每次重写整张图。收到 `max-tokens` 后不执行该条回复，而是保留上下文并要求模型重新给出一个更小的完整动作，最多尝试两次。当前执行中此前成功的工具结果保留；不拼接残缺 JSON，不补猜电路参数。仍失败时可查看和下载原始回复。

这些重试仅发生在用户已启动的模型任务内，最多增加两次截断恢复请求；原有格式修正另有最多两次请求。安装、浏览页面和保存输入均不会请求模型。没有取得用户内网失败原文，无法断言具体是大批对象还是思考消耗触发上限；本更新改善预防和恢复，不宣称已证明 v4.1flash 的内网生成一定成功。

## 更新

下载并解压 [0.4.2 升级 ZIP](../output/packages/EDA_Flow_Update_0.4.2.zip)，在解压目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\update-eda-flow.ps1 -Profile desktop -PackageVersion 0.4.2
```

可从 0.4.0 或 0.4.1 直接更新。自动备份并保留旧项目、配置、登录、窗口运行时和原模型调用开关。仅查看界面时可加 `-DisableModelCalls`。等当前任务结束后，正常退出整个 Harness 并重新打开，确认页面与后台都显示 **0.4.2**。

打开原项目，已确认的第二、三步保持原结果，在第四步重试即可。自动恢复在同一次执行中继续；如果最终失败后手动重试，会使用新的执行目录，之前的文件和记录保留，不把上次失败的半成品当作已完成结果。

本版继续发布到已有 `release/eda-flow-0.4.0` 试用分支，旧的固定提交链接不会自动升级。包含 0.4.1 的 `replayState`、补充入口和 JSON 容错修复。Python 依赖不变，无需额外下载 Node 运行依赖。
