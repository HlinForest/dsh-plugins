# 工程工作台设计

面向实际使用三类工程插件并向管理者演示工作成果的 DSH 用户。新版默认处理用户输入的真实需求和工程；示例只在用户主动载入时使用。原生插件是唯一业务执行入口。

颜色：工作纸 #EDF2F5、面板白 #FFFFFF、字色 #203745、蓝绿 #257D8D、铜黄 #B87527、问题红 #B74745。
字体：Segoe UI / Microsoft YaHei UI，中文正文 14px，结论 26px，工具与表格 12–14px；数值使用等宽数字，不用代码字体装饰标签。

布局：保留 DSH 侧栏入口、工程纸色与可移动悬浮进度。三个业务页独立并保留切页状态。选型以需求原文与逐项证据为核心；PCB 以实际器件、网络和规则发现为核心；原理图以目标、明确条目、候选差异和验证为核心。输入和结论左对齐，宽表可水平滚动，小屏变单列。

```
工程工作台       产品方案 / PCB 评审 / 原理图同步 / 执行记录
需求原文        | 已提取条件、缺失信息、候选对比、资料与报告
工程与检查方式  | 器件 / 网络 / 问题定位、评审结果与监听
当前图与目标    | 证据条目 → 差异 → 候选 → 验证 → 写回 / 回退
```

审视：避免四块同形状 KPI 卡片和装饰性进度条。最显眼的内容是参数变更引起的真实候选变化与原生工程图。只在用户操作后更新图表；执行进度由已完成步骤驱动，不伪造百分比或成功。颜色始终辅以文字。支持键盘、缩放、浅深主题和减少动画偏好。

新版审视：去掉固定电源需求作为主入口，避免用少数控件冒充完整插件。基础流程用表单和结构化结果；仅原始快照、补丁对象和完整数据采用折叠的高级编辑区。修改需求后旧候选与导出失效；修改目标或候选后旧写回凭据失效。写回 / 回退展示确切工程路径并由用户在界面确认。

验收范围：选型 6 个原生工具；PCB 7 个既有工具及会话监听开关；原理图 10 个原生工具。现有插件边界仍生效：不凭缺失证据推断参数、不将局部评审称为整板通过、不将 PDF 文字视为连通性、层级图自动写回不受支持。自动识图仅在原插件已配置视觉服务时提供。

原生界面截图复核：1600×1080 时需求原文与已提取条件并列，差异图能看清 R1/R2 的旧值和新值；430×932 时自动单列、页签可操作、宽表独立滚动，浮动面板可收起。表单标签绑定独立控件 ID，避免有值后可访问名称变化。
