# 工程工作台设计

面向向管理者演示工程能力的桌面 DSH 用户。三个界面都使用真实引擎结果。

颜色：工作纸 #EDF2F5、面板白 #FFFFFF、字色 #203745、蓝绿 #257D8D、铜黄 #B87527、问题红 #B74745。
字体：Segoe UI / Microsoft YaHei UI，中文正文 14px，结论 26px，工具与表格 12–14px；数值使用等宽数字，不用代码字体装饰标签。

布局：DSH 侧栏入口打开一张接近全屏的工作台，标题与标签左对齐。选型页左侧固定参数，右侧是容量图、候选矩阵和证据；电路页以大幅工程图为核心，问题列表占右侧。悬浮面板可独立收起和拖动。

```
工程工作台                 选型 / 电路检查 / 执行记录     收起
参数与演示步骤 | 连续能力与需求线 / 原生图纸及位置标记
              | 候选校验 / 检查详情 / 修改前后
```

审视：避免四块同形状 KPI 卡片和装饰性进度条。最显眼的内容是参数变更引起的真实候选变化与原生工程图。只在用户操作后更新图表；执行进度由已完成步骤驱动，不伪造百分比或成功。颜色始终辅以文字。支持键盘、缩放、浅深主题和减少动画偏好。
