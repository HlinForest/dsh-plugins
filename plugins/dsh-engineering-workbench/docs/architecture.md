# 工作台模块边界（0.3.4）

保留一个工作台入口，按用例拆分阅读、资料接入和工程操作。功能数量本身不要求拆成多个安装包；后台作业、数据持久化和模型调用不能继续依赖某个页面当前显示的页码。

## 已落实的边界

| 模块 | 职责 | 对外接口 |
| --- | --- | --- |
| `manuals.js` / `manual-reader.js` | 整本索引、全文检索、带引用的阅读笔记、按问题阅读、暂停续读 | `index/search/start/status/stop` |
| `references.js` / `reference-reader.js` | PDF / 图片逐页电路识别作业、覆盖进度和恢复 | `start/status/stop` |
| `material-connections.js` / `materials.js` | 发现兼容资料接口、配置来源、分页检索和取得真实 PDF | 来源注册与 `search/read` |
| `model.js` | 器件映射、网络比较、明确规则与坐标换算 | 不依赖 UI、模型服务或文件系统 |
| `tasks.js` | 工程快照、版本、独占修改、证据提交、编辑/验证/导出 | 独立 taskId 和任务动作 |
| `adapters.js` / `reference.py` / `vision.js` | 本机 EDA、PDF 提取与渲染、DSH 当前模型接入 | 受控文件输入与模型调用 |
| `index.js` | 装配服务、认证和 HTTP 路由 | 不承担阅读流程 |

阅读器接收任务加载、任务目录、配置和模型接口，不再持有整个工程服务。识别器接收任务加载、目录、模型能力和单页提交端口，不直接修改 `task.json`。每页识别、两次提取及条目验证在工程任务锁内执行；页面全部成功后原子提交，取消不会留下半页对象。

后台状态与 `task.json` 分开保存。关闭或刷新页面不会终止后台作业；显式暂停及插件退出会取消当前调用，保留已完成批次。进程重启后显示“已暂停”，由用户继续。Windows 文件短暂占用时重试原子替换，不删除旧状态。

## 阅读和比较的真实边界

建立全文索引不等于模型已读懂整本资料。PDF 全文一次索引，文本按最多 6 页 / 16,000 字符自动分批；先阅读全部可用文本；含位图、矢量图形或无文本的非空页面随后补充图像阅读。图像能力不可用时记录未覆盖页，任务状态为部分完成。扫描文字由图像阅读结果补充索引，仍为未人工核对内容。

按问题阅读先检索全部已索引文字，阅读排名最前的最多 12 页，界面显示匹配总数与实际阅读范围。结论需要对应页的逐字引用；文本引用必须匹配原文。图像引用标记未核对，不能自动成为选型规格或人工确认的电路证据。导出包含通读笔记、问题回答、覆盖页数、文件哈希及未覆盖项。

PDF 电路使用支持图像的当前 DSH 模型逐页提取两次。差异保留在每页识别记录和未确认项中；首份结果通过条目与引脚引用验证后作为待核对证据导入。任一 PDF 页未导入或整份资料未识别出器件时，比较入口阻止继续。已识别不等于连接完整，图像网络覆盖继续保持 partial，映射仍需用户确认。

## 后续拆分方向

这次是按真实故障边界做的渐进拆分，并非整仓已经完成 Clean Architecture 重写。`tasks.js` 仍包含候选编辑、验证、保存与回退，可以在后续独立功能改动时继续拆出编辑用例与仓储端口。现阶段不增加空转发层、重复模型对象或多个插件间通信。

数据库自动发现只筛选同一 MCP 服务中不歧义、参数符合手册适配约定的检索/读取工具对，不自动执行未知 SQL。输出仍需符合资料源契约；非标准接口由管理员在高级设置中接入或适配。
