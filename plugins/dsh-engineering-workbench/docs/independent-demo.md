# 六项独立任务：分步演示

适用版本：工程工作台 0.3.1。每个案例都可以单独开始，不必先完成其他案例。所有修改演示都使用小工程副本；不改 DisplayBoard 原工程。

## 准备材料

本机样例目录：`D:/VisualBoard/dsh-plugins/plugins/dsh-engineering-workbench/examples/independent`。

| 文件 | 用来展示什么 |
| --- | --- |
| divider.kicad_sch | 三个器件的理想、无负载分压电路；R1=10k、R2=20k、C1=100nF |
| changed-value.kicad_sch | 只把 R1 改为 22k，连接保持相同 |
| renamed-reference.kicad_sch | R1 改名 R99，连接保持相同 |
| moved-layout.kicad_sch | 移动 C1，连接保持相同 |
| missing-decoupling.kicad_sch | 缺少 C1 |
| dnp-capacitor.kicad_sch | C1 存在，但标记为不装配 |
| shorted-resistor.kicad_sch | 故意把 R1 两端短接 |
| divider.pdf、divider.jpg | 同一张目标图的 PDF 和图片版本 |

PCB 案例沿用仓库已有小工程：`D:/VisualBoard/dsh-plugins/demos/independent/02-pcb/before/FilterReview.kicad_pcb`。这是一块教学用未布线小板，不作为生产设计。

先关闭旧工作台窗口并重新打开 DSH，使新插件生效。在侧栏点击“工程工作台”。需要演示时只打开相应任务即可。读手册、原理图和 PCB 任务各有自己的“新建独立任务”“打开已有记录”和报告目录。

## 演示一：只读一份手册，约 3 分钟

1. 打开“读手册”，选择自己的 PDF。也可以从仓库 `plugins/dsh-megmeet/success-demo/materials` 选一份厂家 PDF。
2. 点击“新建独立任务”。输入页码并读取页面。用放大或全屏查看原始参数表，确认页码是 PDF 页序。
3. 点击“提取两遍并核对”。沿用 DSH 当前模型。两次一致仍是模型草稿，不会自动勾选人工核对。文字模型只能处理有文本层的 PDF；扫描页需要支持图片的模型。
4. 检查草稿中的数值、单位、页码、原文、图页位置和工况，修正后保存。页面提供结构化条目编辑区；每条必须有当前页码、原文和有效位置。
5. 导出资料卡。报告保留文件哈希、页码、原文、位置及“人工核对 / 未验证”状态。在“资料管理”可重新打开该记录。

讲解重点：这里得到的是有出处的资料卡。不是看到两个模型答案一致，就宣布参数已经可靠。

## 演示二：只做真实需求选型，约 4 分钟

1. 打开“产品方案”。此入口需安装产品方案插件并配置真实资料库，其他任务不受其影响。
2. 粘贴客户原文，或打开已有 `demos/independent/01-selection` 的需求文本；不要先打开任何电路工程。
3. 点击“解析需求”，核对解析出的电压、负载、环境温度、安装条件和未知事项。
4. 检索候选，打开某个型号查看逐项依据与资料原件。
5. 在客户原文中提高负载或环境温度，重新解析和检索。展示候选变化以及具体不满足项。
6. 指定候选并导出方案。没有提供的条件保持待确认，不由模型补成固定场景。

讲解重点：选型可以独立完成，不要求先读手册、评审 PCB 或创建工作流项目。

## 演示三：只评审一份原理图，约 4 分钟

1. 打开“原理图评审”，选择 `divider.kicad_sch`，新建任务。
2. 保留原生检查，点击“开始评审”。报告分别显示 KiCad ERC 和扩展检查建议；扩展建议不会冒充 ERC 结论。
3. 展开“扩展规则与工况依据”，添加“去耦”。选 R1 的电源端引脚 1，另一端网络选择实际列表中的 GND 网络，填写依据：“教学样例要求 C1 直接跨接电源与地，检查其装配状态”。再次评审。
4. 另建任务，选择 `missing-decoupling.kicad_sch`，填相同检查。应显示未发现所要求的直接跨接器件。
5. 再选择 `dnp-capacitor.kicad_sch`，显示不装配的 C1 不提供去耦能力。可以导出每个独立报告进行对照。

可选计算演示：添加 LDO 功耗检查，Vin=5V、Vout=3.3V、I=1A，最大允许功耗=1W，工况填写“教学：连续负载”，依据填写“本次明确的 1W 功耗预算”。结果为 1.7W，超出已列预算。这不是封装温升证明；热阻、铜面积、环境温度未提供时不能据此给出完整热设计结论。

讲解重点：原生检查负责基础规则，明确证据和工况的扩展规则负责补充工程检查。缺少手册只影响依赖手册的项目。

## 演示四：只做 PCB 评审，约 3 分钟

1. 打开“PCB 评审”，直接选择 `FilterReview.kicad_pcb`，关联原理图先留空。
2. 新建任务，查看原生板图。点“器件定位与实际焊盘网络”，点一个器件查看实际焊盘与网络。
3. 点击空白取消选择，再选另一个器件。标记不应异常变大，也不应留下旧选中状态。支持键盘 Enter、Space 和 Escape。
4. 点击“开始评审”。这块教学板尚未布线，所以未布线项目不能显示全部通过。报告同时注明未提供关联原理图时，没有执行原理图一致性检查。
5. 如需一致性检查，另建任务并选择同目录、同名的 `.kicad_sch`。再次执行，报告列出实际原生覆盖范围。
6. 导出报告；可识别到器件身份的问题可点击“定位器件”。其他原生问题的坐标与对象明细保留在原始 DRC 报告中。

AD 离线演示：直接选择自己的 `.PcbDoc`。可以读取板图、器件与焊盘网络；没有 AD 原生结果时显示“未执行”。不会把离线库读取成功当成 DRC 成功。

## 演示五：比较两张图，约 4 分钟

1. 打开“原理图对比”。源图选 `divider.kicad_sch`，目标选 `renamed-reference.kicad_sch`。
2. 新建任务，检查 R1→R99 的对应建议。核对引脚后勾选“已核对”，保存对应关系。
3. 点击“比较元件、连接和功能指标”。应看到连接相同；功能指标仍待确认，因为尚未给出计算条件。
4. 换成 `moved-layout.kicad_sch` 新建任务。确认映射后，图面位置不同但连接相同。
5. 换成 `changed-value.kicad_sch`。结果应明确区分“参数不同”和“连接相同”。
6. 展开“功能指标与工况”，新增分压指标：两侧 Vin=5；源图 Rtop=10k、Rbottom=20k，目标 Rtop=22k、Rbottom=20k；两侧工况均写“理想 DC，无负载”，填写对应工程中的数值依据。允许范围设为 3.2–3.4V。
7. 再比较：源约 3.333V，目标约 2.381V；指标不一致，且目标不满足所列要求。报告记录公式、输入、单位和条件。这里的输入需要人工对应实际电路，不能把任意填入的计算数值当作工程自动提取值。

图片/PDF 混合对比：目标改用 `divider.pdf` 或 `divider.jpg`。逐页读取并提取条目，核对后保存。缺少连接、模糊文字和不确定装配状态仍保留待确认。两份图片也可以比较，但不能保存为可编辑工程。

讲解重点：元件匹配、连接相同、已列指标一致、满足已列要求是四个独立结论。没有承诺整电路仿真等价。

## 演示六：向目标对齐、查看真实变化并回退，约 5 分钟

1. **先在文件管理器复制** `divider.kicad_sch` 为 `my-demo.kicad_sch`。源工程选副本，目标选 `changed-value.kicad_sch`。
2. 打开“向目标对齐”，新建任务，核对三个器件对应关系并保存。
3. 在差异清单只勾选 R1 的“数值”，点击“将所选差异对齐到目标”。应生成候选，源副本此时仍未改变。
4. 查看“修改前 / 修改候选 / 目标资料”，放大或全屏。候选 R1 为 22k；修改前为 10k。下方“实际修改记录”显示真实对象变化。
5. 在编辑器搜索 R1 并定位。单击仅选择；拖动才移动。点击撤销、重做，验证数值与图纸都恢复到对应版本。可调整属性、移动、旋转、绘制/删除导线、添加连接点和网络标注；新增器件必须选明确符号并核对引脚定义。
6. 连接或型号差异会建立待处理候选，由编辑器明确处理；本版不会自动猜线或猜替代型号。图片/PDF 或跨格式布局对齐先选择两个已确认器件作为锚点，完成坐标校准，再对齐其他位置。
7. 点击“验证候选”。查看 ERC、实际元件和连接变化、尚未对齐的差异。没有选择的差异继续保留。任何范围内未知项、未声明变化或原生检查错误都阻止覆盖。
8. 可以先导出完整候选 ZIP。包内包括工程主文件、子页、已收集的本地库和文件哈希清单。
9. 如验证允许保存，先保存并关闭 KiCad，再点“覆盖原工程”，查看路径后确认。只覆盖本次候选涉及的原理图文件，自动保存备份。
10. 点击“回退此版本”。系统只在原工程仍等于本次保存版本时恢复备份；后续人工修改不会被覆盖。

未标值规则：现有对应器件保留原值并显示待确认；新增缺值留空。原理图修改不自动更新 PCB，需在 EDA 中处理一致性变化。

AD 候选可以离线生成和导出。当前没有 AD 25/26 环境，不能完成真实软件验收，覆盖 AD 原工程保持禁用。详见 [AD 验收记录](AD-acceptance.md)。

## 演示结束

独立任务及资料卡会保留在工作目录，可从各入口的历史列表或“资料管理”恢复。执行记录显示实际操作耗时；旧任务与旧同步工具保留兼容入口。

验收范围见 [验证记录](validation.md)。10 份手册已准备可定位的标注草稿，但尚未完成人工黄金集验收；这不能对外表述为模型提取准确率已达标。
