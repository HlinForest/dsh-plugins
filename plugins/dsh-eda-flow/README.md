## 使用

在独立 Harness profile 安装本包，通过“电路设计”入口打开七步窗口。新建项目可选“从零设计”或“固定器件 · 通用设计”；后者导入 JSON 器件清单，界面提供格式示例。填写功能、供电、接口、约束即可，不需要坐标或完整网表。第二步整理需求，第三步查询库并提出连接。第三步人工确认后才冻结；第四步只能改纸张、分组、间距、整件旋转。修改器件或连接必须回第三步重新审核。

图纸、实际 XML 网表、BOM、PDF、ERC、碰撞报告和输入字节统计均保存在项目记录。第六步 PCB 本轮不执行。静态检查通过仍为工程草稿，不能等同量产批准。

## 依赖与配置

本机验证：Windows、Node 22+、Harness 0.2.0-rc.2、KiCad CLI 10.0.6、Python 3.10+（jsonschema、PyMuPDF）。ELK.js 0.12.0 随包提供。KiCad、Python 和 Harness 不包含在 tgz 中。输出采用 KiCad 10 文件格式，不承诺向下兼容。

配置项：workspaceRoot、workDirectory、kicadPython、mcpPython、kicadCli、kicadLibraryRoot、catalogFile、allowModelCalls。未配置 catalogFile 时只限制到本机库目录，**不代表企业内部白名单**。配置白名单后检索和精确读取均受限制，清单缺失或解析失败不会退回公共库。
