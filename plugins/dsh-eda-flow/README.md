# 原理图与 PCB 流程 · 0.3.3

独立 DeepSeek Harness 插件，无需安装工程工作台。

**工程师输入 → Harness 当前模型处理 → 工具生成 → 查看结果 → 工程师确认下一步。**

“载入显示板输入”预填完整器件、连接、图形、封装、PCB 几何、模型和已确认调整。第一步可直接人工确认；其他生成阶段调用 Harness 当前模型，工具执行实际生成。新建设计使用同样七步，输入为空，由工程师与 AI 逐步补齐。

## 0.3.3 确认状态与输入入口

新增页面／后台版本核对，确认响应不完整时读取已保存状态；默认资料和待确认项都有直接入口。[更新与生效检查](../../docs/update-eda-flow-0.3.3.md)。安装完成后需核对实际运行版本，仅关闭设计窗口可能保留旧后台。

## 0.3.2 确认与启动修复

修复确认失效后仍跳到下一步、任务启动失败反馈不明显的问题；按文件内容核验，记录具体变化文件。[已有安装更新命令](../../docs/update-eda-flow-0.3.2.md)会保留原项目、模型配置与登录，无需填写工作目录。

## 使用

使用完整内网包按 [安装说明](docs/intranet.md) 安装。环境：Windows x64、Node ≥22.19、Harness 0.2.0-rc.2、KiCad 10.0.6 与其 Python。沿用 Harness 的模型选择和登录。

1. 点击 Harness 的“电路设计”，在独立窗口操作；再次点击会返回已有窗口。点击“新建项目”，选择空白输入或显示板输入。
2. 在当前步骤查看说明、表格和完整数据，填写补充要求；第 3 步可选择本机规格书 PDF 并绑定型号与位号。
3. 第一阶段保存并人工确认。后续使用“整理输入”“生成原理图”“生成 PCB”等具体操作。右栏 AI 助手的建议经采用才写入输入，发送问题不重建工程。
4. 查看图纸、文件、检查和缺项，确认后进入下一步。修改输入会使相关结果失效。
5. 第 7 步下载工程包和冻结记录包；确认后可在第二个空目录重放已记录方案。

工程师填写普通表单或选择本机文件，无需预制内部 JSON。页面支持全屏图纸、资料分段查看、原始线宽图下载。所有文件保存在配置的工作区中。

## 输入与工具

- 默认输入是已验证本机试验的完整 75 个文件；源事实与已确认调整分开保留。
- `skills/eda-inputs/SKILL.md` 由插件自动加载到阶段模型上下文。SchDoc/PcbDoc 读取和 PDF 逐页文字提取在模型处理前执行。
- 显示板的确定性转换器从完整逐对象数据生成工程；生成期间不导入整板、不读取历史成品。模型可以分页读取所有提取文件，选择转换器或生成阶段程序。
- 新设计没有参考电路也可从需求、接口和器件规格书建立依据。复杂电路的真实模型设计能力需内网验证。
- TSD 包装文件会报告缺项及原环境导出方法；不能通过改后缀或删除头部变成有效提取。默认输入无需重新读取 TSD 文件。

## 验证与限制

本机禁止付费模型调用。发布记录区分真实 KiCad 执行、模拟模型接口测试、真实模型待验证；模型失败不会降级成预置答案。

显示板保留源工程 2 铜层设置，走线和铺铜在背面，19 个通孔带正面铜环。实际制造铜层数与孔金属化单独待确认。数码管二维轮廓完整，缺原 3D 模型。原 Altium 编译网表、原始页面 PDF 和规格书未补齐。ERC/DRC 与目标一致性检查各自记录。

通用模型生成的 Python 以 Harness 当前账户运行，适合在独立工作目录试用；输入快照与哈希核验不等于操作系统隔离。详见 [架构与核验](docs/architecture-v2.md)。

## 开发

`npm test` 检查流程状态与真实宿主注册。`test/integration-offline.mjs` 使用明确标注的模型替身运行真实 KiCad 并重放，未打入安装包。`npm pack` 打包插件，整包另附 Python 离线轮子与安装脚本。

## 0.3.0 三栏独立窗口

正式界面按已确认的三栏稿实现：左侧七步流程、中间页签与数据、右侧按项目及步骤隔离的 AI 助手。窗口优先使用独立桌面运行时，由插件后台提供仅绑定回环地址的认证接口；凭据和模型调用仍在 Harness 后台完成。插件只注入宿主图标入口，不注入聊天遮罩、工程浮层、快捷键或全局样式。

项目切换只选择已有工程，名称、创建时间与短编号共同区分。仅“新建项目”创建可见实例；重试与空目录重放保留在操作记录。支持改名、上传本机文件、查看输入、模型错误详情和实际生成文件。已有项目不合并、不删除。

本地开发验证使用 `test/serve-ui.mjs` 和模型替身，均不进入安装包；正式安装没有模拟模型开关或硬编码回复。具体检查见 `docs/ui-0.3.0.md`。

## 0.3.1 视觉细化

保留三栏、七步与原有操作，对齐 Harness 的白灰底色和 8/12/16/20/28px 圆角层级。品牌图标 24px；独立窗口标题栏 40px，与下方顶栏同为 `#f9fafb`。宿主入口为 40px 按钮中的 20px 图标，悬停显示“电路设计”；加载与失败不挤压旁边的插件。

桌面运行时独立放在工作目录的 `desktop-runtime`，不更改 Harness 的依赖与登录；安装方式见 [桌面窗口](docs/desktop-window.md)。未安装该运行时时回退到 Edge，但其原生标题栏样式不同。可复用 UI 规范与技能保存在仓库 `skills/megmeet-dsh-plugin-skills`。
