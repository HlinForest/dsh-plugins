# 工程师文字评审与安装依赖

## 评审和微调

在原理图、PCB 等步骤下方打开“工程师评审与微调”，或从左侧进入“工程师评审”。

1. 选择修改步骤：器件、参数与接法 / 原理图排版 / PCB布局布线。填写问题、期望效果、需要保留的内容；可填写评审人署名。所选步骤需有当前有效结果。
2. 点击“保存评审意见”。只保存原话和针对的版本，不修改工程、不调用模型。
3. 点击“采用意见，准备修改”。意见加入所选步骤的可见文字输入，该步骤及其后续结果变为待更新。
4. 查看输入和工艺字段，点击“按评审重新生成”。走原有的生成及检查流程。若意见与工艺字段冲突，先同步修改明确的字段；不能以文字绕过冻结的连接、封装和工艺要求。
5. 打开修改前、修改后图纸，对照实际距离、DRC/ERC等结果。点击“确认这条意见已解决”，或填写复核说明后点击“仍需修改，追加意见”。后一种情况新增一条针对新版本的意见，原话及原结论保留。

每条记录保存署名、时间、原话、针对的输出版本和摘要、采用时间、每次执行的输入摘要校验值、前后输出校验值、检查结果、失败/中断记录和人工复核结论。历史图纸读取时校验文件内容，文件变化后不冒充原评审版本。署名是工程师自填，不是身份认证或电子签章。

新生成的PCB评审记录还保存走线总长、小于0.5 mm的线段数、二度连接拐点和同网铺铜覆盖的重复走线清理量。总线长只统计明确的走线段，不包括面状铺铜，也不等于整条信号路径或返回路径。历史版本若没有这些字段，不伪造历史测量值。

布局按已确认的接口滤波角色、唯一接收端和实际返回网络推导局部放置偏好；多接收端等无法唯一判断的情况不擅自指定归属。铺铜网络不按虚拟直线交叉计罚。重复走线仅在完整铜形被同网、同层的实际填充覆盖时清理，并在重新填铜后再次核对；若覆盖消失则恢复线段。候选在错误和警告相同时继续按实测线长、短段和拐点评估，最终仍须通过原生DRC、连通与图面复核。

“已生成，待工程师复核”不等于“意见已解决”。DRC通过不会自动关闭评审，也不会替代阶段确认或最终交付签核。记录可独立导出为JSON，第七步重新导出工程时也附带当时的评审记录快照。后续复核发生在导出之后时，需重新导出记录或交付，才能包含新结论。

修改失败或中断时保留旧图和意见，可重试。若输入或图纸版本已变，旧的未采用意见不能直接套到新版本；需针对当前结果再评审。历史版本保留用于比较，当前尚未提供一键回滚或跨电脑的项目导入界面。

## 工程师电脑需要的软件

| 项目 | 用途 | 取得方式 |
|---|---|---|
| DeepSeek Harness | 插件宿主、模型配置与登录 | 工程师或IT原有部署；不含在本交付包 |
| 本插件TGZ | 七步流程、评审、生成协调 | 本交付包 |
| KiCad 10 稳定版 Windows x64 | 原生原理图、PCB、ERC/DRC及编辑 | 官方完整安装器；本机验证10.0.6 |
| KiCad符号库与封装库 | 真实库资源与封装读取 | 随官方安装器安装；不要只复制kicad-cli.exe |
| Python依赖 | PDF提取、几何/约束求解、工具接口 | 完整包offline/wheels，安装到配置的解释器；推荐KiCad配套Python |
| Java 21或以上 | 运行自动布线器 | 完整包offline/java21已提供，配置其bin/java.exe |
| Freerouting | 自动布线 | 已随插件提供，不需另找安装包 |
| 可访问的模型服务 | 方案、布局建议与文字处理 | 在Harness配置；内网需能访问相应服务 |

无需安装Altium Designer即可生成KiCad工程，也无需先打开KiCad编辑器。CAD编辑器界面用于工程师手动检查或修改。3D模型影响3D预览，不是本轮二维生成和DRC的必需依赖。普通Python不能替代PCB所需的pcbnew；分别配置解释器时，各自的依赖要在对应环境安装。

## 没装KiCad怎么处理

推荐让IT在目标电脑安装KiCad 10稳定版完整程序、符号库和封装库。从[KiCad官方Windows下载页](https://www.kicad.org/download/windows/)获取；官网也提供历史稳定版入口。离线内网可以从联网电脑下载完整安装器，转入后安装。库默认随相应平台安装器提供，见[官方库说明](https://www.kicad.org/libraries/download/)。不使用11系列夜间开发版替换本轮验证的10系列接口。

安装后按完整交付包使用说明执行 `install/install-offline-python.ps1` 和 `install/install-intranet.ps1`，配置KiCad的bin目录和Java路径，重启插件。左侧“环境与安装”点击“检查本机环境”，逐项查看路径、版本、Python模块、库和Java。检查不发送模型请求；模型仅显示选择状态，不据此宣称连通或额度正常。

如果暂时不能安装，安装脚本支持 `-ReviewOnly`，此时可以省略 `-KicadDirectory`。这允许插件加载、保存文字输入，并在同一已保存的插件项目上查看已有图纸和记录评审；不能重新生成、运行ERC/DRC或把静态图片变成可编辑工程。独立Demo也能直接查看。补齐KiCad后，用相同profile和工作目录重新运行安装脚本，传入KiCad目录并省略ReviewOnly，再检查环境。

当前只有本机工具执行；没有“自动把CAD任务发到另一台电脑”或远程CAD服务器功能。不能在本机安装时，需要由已部署完整工具链的工程电脑执行生成；仅查看Demo/PDF的电脑不需要安装KiCad。

走线清理以实际铜形状为依据：同网络、同层的已填铜区或焊盘必须完整覆盖待删除线段；锁定走线和过孔保留。铜区清理后重新填铜并复核，焊盘内微小折线按焊盘铜形状核对。清理前后显式走线长度分别记录，不能把删除重叠铜线等同于缩短信号或回流的实际电流路径。最终仍核验全部网络、原生 DRC 和图面质量。

自动布局反馈最多尝试9个不同组合：优先断开的信号端点，同时保留累计反馈、单网反馈和可见最小间距推导的间距分支。某个组合退步时仍保留此前最佳候选，不会因为反馈集合重复而提前跳过全部剩余尝试。搜索有上限，结束仍未连通时如实保留失败结果，不能交付为通过版。
