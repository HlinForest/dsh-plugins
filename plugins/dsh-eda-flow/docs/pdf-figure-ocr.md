# PDF 应用图文字提取

可复制正文与图像混排的页面，以前即使标为“已读取”，也可能漏掉应用图里的阻容数字。现在提取器另行检测较大的嵌入图像；在资料提取 Python 已安装 RapidOCR 时，本地识别图中文字。未安装时保留待查看区域，正文提取照常进行。

在“实际输入”中可见文件名、页码、区域位置和识别原文。附件及阶段资料快照保留每行置信度、文字位置、原 PDF 哈希。识别结果单独保存为 figureObservations，不进入规格事实或可引用的 evidence。核对原 PDF 中的符号、单位、接线关系、料号与版本后，工程师可将确认的内容连同来源和页码写入“规格书正文与来源”；它会明确保留为补充正文，而非冒充自动提取的 PDF 文字。

## 安装

使用配置的资料提取 Python 安装 mcp/requirements-ocr.txt。联网机器可用该解释器的 pip download 下载完整依赖；内网用 --no-index --find-links 指向离线包目录。依赖须匹配部署的 Python 版本和 Windows 架构。当前实际验证为 Windows x64、CPython 3.11、RapidOCR 1.4.4 / ONNX Runtime 1.20.1。安装不需要也不会上传 PDF 到第三方 OCR 服务。

OCR 是可选组件，插件 TGZ 不包含这些模型和 Python 依赖。“环境与安装”单列其状态；可导入不等于每页识别正确。RapidOCR 项目及包元数据提供其许可证与依赖信息：https://github.com/RapidAI/RapidOCR ，https://pypi.org/project/rapidocr-onnxruntime/1.4.4/ 。部署离线依赖时同时保留各依赖的许可证。

## 本轮实际验证

外部候选规格书 Everlight IRM-36xxM3 Rev.7（经销商发布的厂家文件）第 2 页，普通 PDF 正文没有读到应用图中的 47–220 Ω、≥2.2 µF 和可选 ≥10 kΩ。新增识别实际读到了这三个条件。该文件没有随插件打包；本板 IRM-3638M3-X 的后缀适用性尚未确认，所以未据此改本板参数。

## 边界

当前处理嵌入的栅格图像，不能识别图中导线拓扑，也不保证覆盖所有矢量图、碎片拼图或极小文字。每份文档最多识别 12 个区域，OCR 累计预算 45 秒，单区域最长边不超过 1800 像素；未识别或超预算的区域均保留状态。OCR 结果不会写入规格附表解析器，也不会根据高置信度自动批准选型。
