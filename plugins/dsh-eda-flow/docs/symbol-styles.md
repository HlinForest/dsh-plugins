# 原理图符号样式与引脚身份

默认生成采用用户指定的 AD 图纸画法：有明确三脚供电/地/输出事实的红外接收器使用竖向受光图标；连续编号单排连接器使用矩形、编号从上向下递减；资料明确为两位数字、四个指示标记且为十脚的显示模块使用阶梯轮廓，上排 10–6，下排 1–5。不符合这些条件的器件继续使用已有通用画法。

这是符号内部图元和引脚位置的样式约定，不是显示板的整页布局模板。不会读取 AD 工程或导入板级网络、器件坐标、数值、封装。原理图外形也不是实物尺寸或 PCB 封装。显示器的旧版非网格引脚位置归整至 1.27 mm 网格，指示圆绘制为完整圆；不宣称像素级复制。

引脚编号、名称、电气类型及焊盘编号仍来自当前规格书和器件事实。符号内的图案不参与电气连接；引脚的位置会影响自动布局、走线和图纸阅读，因此改样式后必须重新布线并比较原生网表。不能仅凭 ERC 通过宣布与 AD 一致。

新项目在第三步生成并审阅这些符号。已经确认的项目保留旧版符号快照；更新插件后，需要重新执行第三步并确认，再重跑第四、第五、第七步。不能偷偷替换已冻结的符号内容。

AD 图纸的无引脚对象（定位孔、光学定位点、标签、条码、认证标识和工艺说明）属于机械/装配资料，四份电气器件规格书不足以确定其完整内容。它们与用网络标签连接的 0 Ω 跨线电阻不同。不得为了外观相似自行增加或接入电气网络。
