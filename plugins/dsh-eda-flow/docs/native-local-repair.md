# 完整布线后的局部修复

适用于明确指定单个布线层的工程。先按普通流程布局并用 Freerouting 布线；若尚无通过结果，插件保留最多三个只有未连接问题的较好候选，依次尝试局部修复；总预算六分钟，单候选最多五分钟。提前结束的候选会让出未用时间，后续候选各保留至少十五秒的启动预算。找到整板通过结果后停止，不因断线板的短段较少而排除其他种子。

1. 从本次 PCB 的实际断点识别可移动的既有零欧跨线，不增加器件或网络。
2. 根据板框、真实封装、间距和可达铜线搜索合法位置。
3. 重新填铜，从实际铜形中识别孤立回流焊盘；只对已经声明为接口滤波的器件搜索附近位置。
4. 完整接通后再比较同网接入点、缩短折线。每次缩短后都重新填铜，造成断连的改动立即恢复。
5. 整板 DRC、原理图一致性和实际铜岛连通均通过，且器件身份、网络、装配面、固定位置及受保护供电几何保持，才替换本次候选并刷新预览、焊盘表和报告。

所有位置来自当前生成板的搜索结果；不向模型提供参考板坐标，不添加外部逐脚连线。工具输出保留每个候选及拒绝原因。搜索有上限：当前为一个已有跨线器件与局部接口滤波调整，不能承诺多个互相耦合断点、多层板、射频或复杂高速约束都可自动解决。

DRC 和物理连通通过只是候选可继续评审的条件。仍需比较走线长度、短段、拐点、实际供电与返回路径，以及电气和制造要求；不会自动关闭工程师意见。电阻、电容参数仍依据规格书与工作条件推导，资料不足的项目不会因为 PCB 通过而变成已确定。

KiCad 打开或检查工程时生成的临时锁文件不计入图纸版本。真实工程字节变化仍会使结果失效；只有历史失效完全由这类锁文件导致，且现有文件与原摘要完全匹配时，才恢复“已生成”状态，人工确认需重新进行。

共线清理允许跨过分叉接点合并同宽、同层、同网的主线，分支保留原位并接触同一铜形。只减少分段，不移动导线；整数共线、反向连续和铜形一致性检查仍必须满足。

同一项目的再次生成会检查最近已生成的候选。仅在器件、参数、封装、工作输入和工艺约束一致时参与比较；随后用本次新建工程的实际焊盘、网络、板框、装配面和受保护位置复验，并换入当前原理图、库及设计规则，再做完整 DRC、实际铜形连通与距离检查。已有位置只是候选的初始状态，不变成固定坐标约束；新结果必须在连通和布线质量上更好才能取代它。输入发生变化时拒绝复用；记录明确区分新生成结果与重新核验的既有生成结果。当前最多核验两个候选，并非参考 AD 工程导入功能。

已有候选通过本轮完整复验后，搜索进入布线质量优化阶段（最多三次），不再穷尽断点布局分支；未通过的新候选不能覆盖已连通结果。

每个新布局候选在独立原生进程中运行，单候选最多五分钟；新布局搜索的启动预算为八分钟，超出后不再启动新候选；后续局部修复只使用本轮十三分钟预算内的剩余时间。正在结束的原生检查与文件保存仍需少量收尾时间，整个工具任务另受执行超时约束。完整候选在继续搜索前保存到输出目录，并标记为 checkpoint；只有正常完成整轮后才标记 complete。工具超时与人工取消分别记录。若整轮被外部中止，检查点可供后续复验，不作为本次已完成结果发布。
