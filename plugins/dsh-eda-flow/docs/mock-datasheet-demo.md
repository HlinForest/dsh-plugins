# 显示板：自然语言与外部规格资料

显示板项目使用与空白项目相同的七步文字设计流程。创建项目后，任务书、供电、接口、装配、验收和每一步的补充说明都会在页面中直接显示，并且可以修改。保存输入与启动模型是两个独立动作，修改后的文字会进入后续处理。

## 外部资料

关键器件的参数、引脚和装配信息通过项目资料上传。本轮演示使用以下四份外置 PDF，完整交付包将它们放在 `demo/关键器件资料`：

- `TM1616_器件资料.pdf`：显示驱动器引脚、电气条件和应用信息。
- `LED_显示模块资料.pdf`：模块引脚、显示组织和已知机械尺寸。
- `IRM-3638M3-X_器件资料.pdf`：红外接收器型号、引脚和已知机械尺寸。
- `6Pin_2.5mm_连接器资料.pdf`：主板接口定义和已知机械尺寸。

内网按对应型号上传厂家原始规格书；插件不限定四个器件或固定文件名。参数不完整时保留待核实项，不从验收用的 AD 工程补入历史阻容值和完整连线。

在第二步添加文件，在第三步绑定型号或位号并核对正文和来源页码。扫描页、缺页或无法读取的页面保持为待补事项；页面中的“页码待核对”表示项目记录中没有足够的页码证据。其余普通电阻、电容和连接器可以按文字约束从本机通用库选型，特殊器件仍需提供足够的封装和引脚信息。

规格书不是项目创建时的隐藏输入。未上传时页面显示待上传，已上传时显示文件名、读取状态、正文长度、绑定对象和来源记录。模型只使用已经保存并标明来源的资料。

## 七步流程

1. 在“任务与约束”中确认功能、供电、接口、板框、制造和验收要求。
2. 在“资料与提取”中上传外部 PDF 或其他工程资料，查看按页读取的正文和来源。
3. 在“器件与规格书”中核对准确型号、引脚、电气参数、封装和装配状态。关键参数缺失时保留待确认项。
4. 在“原理图”中生成并查看本次图纸、连接关系和 ERC；需要调整时在可见的文字输入中补充要求并重新执行。
5. 在“BOM 与封装”中核对物料、采购型号、DNP、封装标识和引脚映射。
6. 在“PCB”中确认板框、孔位、铜层、布线面、线宽间距、布局约束和制造要求，查看实际布局、布线与 DRC。
7. 在“核验与交付”中查看结构、网络、参数、依赖、ERC/DRC 和待办，确认交付文件。

每一步的输入、模型请求、工具执行、文件和确认记录会按项目保存。下游结果会随上游输入变化而要求重新核对；页面不会把失效图纸或旧检查结论显示为当前结果。

## 关键器件资料的最小范围

不需要为每个普通器件准备独立规格书。至少为决定电气连接、特殊封装或机械配合的器件提供准确型号和相应页面。其他器件在任务书中给出参数范围、封装偏好和装配限制，由模型结合通用库完成选型；若库中没有可匹配的焊盘或引脚几何，流程会保留缺项供工程师补充。

## 历史项目

历史项目继续保留其原有输入、来源、文件和检查记录。历史资料中的来源标记、缺页和页码待核对状态按原记录展示；新建显示板项目从当前可见文字输入和本次上传资料开始，不会覆盖历史结果。
