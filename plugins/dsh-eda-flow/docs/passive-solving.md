# 联立阻容推导与当前计算说明

步骤 3 在恢复或建立候选后使用 `design_solve_passives`，参数仅为本次 `candidateId`。它从实际器件、网络、已记录的规格引用及工作条件求解，不接受参考工程参数、坐标或较宽松的新条件。

求解范围包括：限流支路与扫描公共端电流、该电源域的扫描和偏置增量、储能电荷预算、单级供电电阻及输出上拉、上游跌落传入本地 RC 的首个响应窗口。数值搜索给出保持其他条件不变时的条件区间；各区间不能当作互相独立的自由选值范围。多个参数一起改变必须重新联合计算。

现有参数违反条件时，工具提出实际 `components` 修改，可用 `design_amend` 采用并重新完整审查。优先修复储能不足，避免用降低负载电流来掩盖电源不足；采用 E12 电容 / E24 电阻作为工程候选，仍需核实采购、封装、容差、额定功率/电压和偏压特性。来源规定与数值可行性冲突时保留设计决策，不覆盖资料要求。工具不自动确认或冻结设计。

现有值可行而缺少目标时保持原值。缺少亮度/平均电流目标，不能仅由电流极限推出唯一电阻；缺少输入电容或上升时间，不能确定上拉阻值上界；总容量不能决定并联只数、高频去耦组合或封装。当前修复调整已有阻容，不自动增加、删除或重连器件，也不声称具备任意拓扑模拟能力。

电容修复保留其他并联成员，只调整已有的最大储能电容。该限制适用于现有集总模型；若最大电容被来源固定、存在多级滤波、未知稳压环路或需要改变数量，应返回方案决策并补充适用资料，不通过更改假设使某个组合通过。

发布摘要只从实际清单和工作点记录生成；模型原始叙述留在执行记录中，不代替当前计算。当前数值说明由 `engineeringReview.operatingPoints` 生成。旧的工作点输入说明会随当前输入替换；能明确对应到单个工作点、且与当前结果冲突的压降或时间常数退出当前结论。设计依据中的明确错误数值会修正，周围的资料缺项继续保留。原文保存在“已替换的计算说明”中。该机制不修改用户输入、PDF 引用，也不声称能理解并消除任意自然语言矛盾。

验收仍须比较实际原理图器件、参数、逐脚连接、NC、原始网络和图面。算式正确、条件可行、ERC 通过均不能代替参考工程对照或实物验证。
