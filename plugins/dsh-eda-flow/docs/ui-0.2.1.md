# 0.2.1 界面与隔离修正

入口为 Harness 侧栏的「电路设计」。继续使用原有项目目录、输入数据和当前模型。

## 修正内容

- 用浏览器原生模态窗口承载独立页面，避开 Harness 顶栏；其他插件不能穿过窗口接收点击或焦点。
- 返回按钮位于插件自己的标题栏。关闭和重开保留当前页面与未提交的输入；Escape 先关闭资料或图纸弹窗，再退出工程窗口。
- 将主内容滚动区和底部操作栏放在同一布局中，操作栏不再覆盖表单。侧栏可独立滚动。
- 宽窗口并排展示输入和方案／结果，小窗口自动纵向排列。移动尺寸可横向选择步骤，并在工程选择器创建工程。
- 默认文件清单折叠；刷新进度时保留页面滚动位置、表单焦点和展开状态。

## 依赖边界

运行仍只使用 Harness 的插件入口、连接接口、工具服务和当前模型。工程工作台不是运行依赖。窗口通信仅接受本插件内嵌页面的关闭消息，不访问或修改其他插件的状态和样式。

## 本机验证

9 项服务端测试通过；浏览器回归覆盖新建设计、保存输入、本地文件选择、默认资料读取、真实 PCB 预览、5 种窗口尺寸、桌面模态窗口和关闭／返回行为。本轮没有执行生成或调用付费模型。

真实 UI 截图与检查记录位于本机 `output/EDA_Flow_UI_20261014/`。0.2.1 不改变工程生成逻辑、默认输入或已生成工程。
