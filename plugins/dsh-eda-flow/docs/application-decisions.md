# 规格书建议如何进入设计

第二步保存带原文引用的供电、接口与应用建议。第三步必须逐条说明本次方案如何处理，不能只在提取摘要里出现，随后在选型时消失。

处理方式包括采用、调整后采用、不适用和尚未确定。采用建议时记录实际器件；明确的外部阻容值及数量由宿主对照。规格书的内部上拉等器件自身参数不变成外加同值电阻。调整外部阻容参数时记录理由、参与评估的器件、实际工作点计算和未确定条件。工作点仍由原有供电、限流及偏置检查复算；这项记录本身不证明计算假设正确。

在“器件与规格书”的参数核对页，可以查看“资料建议与选型决策”，展开后查看原说明、选用器件、理由、关联计算和未确定项。这些记录随方案冻结、导出和独立比较保留。

数量读取区分总数和逐对象数量。明确列出的信号如 A、B、C 各一颗，按三颗核对；对象总数没有说明时保留数量歧义。限定的英文/数字信号名列表可计算，目前不完整理解自然语言范围、复杂条件与多组累加。数量核对也不替代每个引脚的实际连接检查。

这是来源到选型的核对，不是完整电气语义证明。不同组合可以成立，但需留下依据；引用存在、值相同或 ERC 通过都不能证明额定条件、网络功能、频率响应或实物性能与参考工程一致。没有负载、扫描或噪声要求时，不补写成已知指标。
