# 接口与局部电路联合布局

在通用分组之后，插件尝试把相连的小型接收电路与一个接口组合成可布线区域。当前覆盖三脚红外接收器、一个接口、局部供电电容组、可选上拉，以及供电/返回/信号路径上各至多一个串联电阻。识别仅依赖当前器件类别、引脚角色和网络；不读取 AD 的板级连接、参数或坐标。

多颗并联电容必须明确属于同一负载、同一供电与返回网络。支路存在歧义、混入其他器件或冻结模块时，不推测归属。接口其他脚保留标签或明确的 NC。已经存在的联合分组也能试算朝向；用户明确指定的分组不合并，明确旋转或绘图约定不改。

元件位置按实际引脚行、符号本体、文字边界和间距计算。供电和返回路径保留真实导线，上拉的出线末端落在输出直线上，避免产生只为接入支线而出现的小台阶。器件本体和文字分别作为障碍，不把两者之间的空白整体封死。三种间距候选均需实际布线，结果记录在 `layout-search.json`。

默认布局与组合布局同时保留。最多八种原有朝向，加上最多八种联合布局候选。每个完整图纸候选分别经过原生网络、器件参数、NC、PDF 几何、ERC 和走线检查；失败候选不会替换已通过结果。

选择分两层：同一分组先比较实际线长、折点、交叉及纸面范围；再比较不同分组的优胜候选。第二层还计算通过标签相连、但没有连续实线的引脚集合之间的曼哈顿距离下界。这样不会仅因把局部实线换成标签而取得低线长分数，也不会为缩短标签间距牺牲组内走线。它是阅读成本的估算，不是开路判定或物理布线长度。

这是有界搜索，不保证全局最优，也不保证所有红外或接口电路都符合该拓扑。未支持的结构仍走通用布局；实际电路参数不在排版阶段修改。图面和 ERC 通过均不能代替 AD 的器件、参数及原始网络比较。
