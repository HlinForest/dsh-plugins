# 局部供电布局

当前布局依据本次已确认方案的网络、引脚方向、符号和文字尺寸计算。模型不需要提供位置坐标，AD 图纸仅用于生成后的独立比较。

从 0.13.8 起，支持的驱动器输入滤波与去耦电容组会联合试算朝向和局部位置，不再只使用一次默认朝向。普通电容组保留原引脚身份，最多试算八种整体旋转组合；显式旋转、指定绘图外观和冻结模块不参与自动翻转。没有明确旋转约束时，第四步应省略 `rotations`，不能把之前输出中的自动朝向复制成强制输入。

每种朝向都先对不同侧的去耦位置与滤波行做有界局部布线搜索，再生成整页。候选必须分别通过原生器件/参数/网络/NC、局部实线、PDF 几何、ERC 和走线质量检查，才进入比较。先保留较小纸张，再比较实际导线、转弯、无连接点交叉和内容宽高的加权代价。权重是公开的阅读性启发式：一个转弯计四个 1.27 mm 网格、一个无连接点交叉计八个网格；并非电气性能或全局最优保证。`orientation-search.json` 保存所有候选、失败原因、耗时、指标和选中项，`layout-search.json` 保存局部候选。

本轮还将驱动器已确认去耦组的供电与返回端作为完整局部回路；不再只画供电线、把每颗电容的返回端拆成标签。输入滤波组保留自身短返回母线，和主电源返回的关系仍按实际网络表达。普通库电容没有 `appearance.kind` 时也会识别该输入返回组，修复了此前只有指定外观符号才能进入该规则的问题。其他功能组不会因共地被拉进同一条大回路。

从 0.13.7 起，同一功能组内、多个输入共用返回端的普通滤波电容可以使用竖排位号和数值，保留完整文字边界；指定外观、显式绘图规则和冻结模块不改。串联输入器件位于滤波分支的外侧，输出支路保持靠近驱动器。支路先尝试沿实际引脚行排列，仅在实测符号或字段不能容纳时扩行；电容端子的出线末端也必须避开第一条输入线，不能只检查器件本体。

去耦位置搜索同时保留信号支路通道。并联排列方向与电容组位于芯片哪一侧独立试算，候选偏移来自实际障碍物边界。比较引脚出线距离和器件组占用宽高，再交由完整局部路由及原生网表、PDF核验。该搜索仍是有限候选和顺序求解；没有联合搜索所有符号朝向，也没有保证全局最少交叉或最紧凑页面。不能把候选评分当成图面验收。

旁路电容使用已确认的负载、电源脚和回流脚归属。储能评估中明确属于同一负载的电容，只有在真实电源和回流网络均吻合时，才随负载一起布局；共享电源名称本身不能证明归属。多个负载争用一颗储能电容时保留其独立位置，不能按遍历顺序分配。

并联电容沿引脚出线方向保留完整走线空间，垂直于出线方向使用实际符号和文字尺寸计算间距。电容容量、数量、连线均沿用已确认方案，排版不会替换电气设计。

红外接收外围根据网络关系区分供电串阻、输出串阻和上拉。上拉可接上游电源或本地滤波电源；本地上拉不再被误认成第二颗供电串阻。当前紧凑规则覆盖一颗接收器、一颗供电串阻、一颗上拉、一颗输出串阻和旁路电容组。多颗电容需明确归属同一负载，且实际供电、返回网络与引脚方向符合该局部拓扑；其他组合进入通用布局，仍需图面核验。

从 0.13.3 起，旁路电容组不再限制为一颗。电容沿共同供电支路排列，各层间距使用相邻器件的实际符号、文字和引脚边界计算；数量、容量和连接来自已确认电路。排序不依赖输入数组顺序。该变化只扩展绘图能力，不会自行增加第二颗电容，也不替代高频旁路的选值计算。

从 0.13.1 起，红外旁路到供电支路的距离按引脚相对位置和实际符号/文字边界计算，不再额外加上整个带端口预留的框高度。缺少可用边界时保留保守处理。

输入滤波电容组先生成可布线的保守位置，再在正文和字段间距允许的范围内按原生网格试排，最多试 12 个向内步长。每个候选都需完成全部局部连线；仅在布线成功时比较总路径长度、转弯和占用面积。布不通的更近位置不能替代已通过的候选。`layout-search.json` 保存候选、局部路由结果和选择分数。这是有边界的局部搜索，不保证全局最优。

只有原本以网络标签结束、没有后续局部走线的端子，才会尝试缩短标签引线。标签位置必须避开器件、字段、脚号、已有标签和其他线路；最终裁去没有引脚或标签锚点的线尾。功能支路的实际连线和电气网表保持不变，不能用这一步掩盖遗漏的局部连线。

从 0.13.2 起，当局部线路垂直于引脚朝向离开时，标签会在同一个实际连通区域内寻找安全的现有线段锚点；不再要求最先遍历到的引脚必须有朝外的直线。标签移动不能跳到同名网络的另一段孤立区域。器件位号变化或存储顺序变化后仍需通过原生网络和PDF核验。

页面优先使用 A4，只有实际功能块无法容纳时才升大。网络标签使用保守文字边界避让，最终仍读取原生网表并检查实际 PDF。ERC 通过、线长减少或页面缩小均不能证明与参考工程一致。验收应分别比较器件、参数、每个引脚、原始网络和图面。

从 0.13.4 起，接口电源/返回端若通过无分叉的两端支路连接串联电阻、电感或磁珠，且用途已确认是供电滤波或跨线，绘图会将其归属接口。共享电源、其他负载、已有归属、原子模块和第二个接口都是停止条件；不能从公共电源继续吸收其他器件。只有同一功能组内已识别的支路保留真实导线，其他供电标签规则不变。直接连接接口的普通电阻根据实际引脚方向选择朝向，两器件支路用实测符号与文字边界计算直线间距。较长链路和不同符号仍需通用布线核验。

页面排布统一分组与连接的处理顺序，试算行、列候选，以占用宽高和功能块之间的信号关联距离评分。六组以内枚举组顺序，更多组使用五种有界排序；再将最优候选作为约束求解的起点，限时求解若更差就保留候选。`page-placement.json` 保存试算数量和分数。输入的显式分行约束仍有效，计算不使用 AD 坐标，也不保证全局最优。改变位号后仍须验证，序列化顺序稳定不等于所有重命名后像素完全一致。
# 同网支线与折点

新增支线连接到已经连通的同网导线树，不再总是独立绕回原始器件引脚。只允许在真实已布导线上接入；孤立的同名标签或引脚不能冒充已有连接。其他网络的交叉点不能作为 T 接点，器件及文字障碍继续生效。

路径评分同时考虑接入处和目标引脚出线方向：延长已有直线时消失的旧拐点计入收益，转入引脚出线新增的拐点计入代价。支线的每个折点按十六个 1.27 mm 网格的路径代价计分，允许增加一段短线以拉直公共导线；这是一项可复测的绘图偏好，不是全局最优保证。仍保留避障必要的折线。最终原生网表、局部导线连续性和图面检查共同验收。

整页排版比较相关功能块边缘之间的空白距离，而不是强迫其中心对齐。接口可以同时靠近两个功能块，即使这些块的尺寸和连接信号数量不同；块内电路整体平移，不修改器件网络或引脚位置。

从 0.13.10 起，小型接收器与接口可作为联合布局候选。先为每种分组选好局部线条，再考虑标签之间隐藏的联系距离；最多保留十六种完整图纸候选。支持范围、真实返回线和失败回退方式见 [接口联合布局](interface-clusters.md)。
