# 扫描负载、储能与本地滤波的联合计算

适用范围：一只驱动器依次选通一个公共端，各显示支路串正阻值限流电阻。宿主从候选网表确认路径、驱动器、电源域及公共端；零欧桥仅用于电气域分析，原始网络仍原样保留。不按型号、位号、参考工程值或坐标匹配。

在 `resistor-load` 工作点填写 `driver` 和带来源/假设的 `inputs.scanSlots`（单位 `count`）。`duty` 是单支路总占空比，不能超过 `1/scanSlots`；可选 `scanFrequency` 为完整扫描帧频率。未知频率保持未定，通信时钟不替代扫描频率。

宿主按实际电阻逐支路计算名义电流 `(V−Vf−Vdriver)/R`，并用压降下界计算条件上界。缺少下界时使用非负 0 V 包络，假设电源不超过声明电压；这不是硬件保证。可明确给出 `minForwardVoltage`、`minDriverDrop` 的条件依据。`maxPeakCurrent`、`maxAverageCurrent` 和可选 `maxGroupCurrent` 分别约束单支路和公共端合计。绝对最大额定只能作为不能超过的边界，不能证明正常工作。

同一时刻只计一个公共端的所有支路，不乘显示位数；供电平均电流再乘实际公共端数与单支路 duty。电容负载阶跃使用峰值上界，不能乘 duty 后低估瞬态。

内部上拉、下拉无需额外安装电阻，但会消耗供电。当前已确认应用指导有明确型号、引脚组、方向及阻值时，宿主从逐字引用解析并按实际引脚核算。输出与偏置相反时按轨到轨电流包络；有已验证的逐公共端扫描路径时只计一个公共端有效。它不依赖某款芯片的专用数值表。来源模糊或冲突会阻止忽略，阻值容差、输出摆幅和切换重叠继续待核实。

供电工作点必须声明 `loadStepScope:"excluding-derived-loads"`，`loadStepCurrent` 仅表示未建模的残余增量。扫描支路和本域外部上拉由真实连接自动加入。残余仍应考虑内部偏置、自身消耗变化和未单独建模的下游负载；假定为零也须列为待核实条件。

`supportTime` 是上游供电响应窗口，不能从扫描槽数或通信时钟自动得到。按 `ΔV=ΔI×ESR+ΔI×t/C有效` 约束实际并联电容。更改段电阻会更新负载、压降及容量下限，现有小电容不满足时必须修改实际候选后重新评审。

对已建模上游电源后的单级 RC，进一步按实际串阻、有效本地容量及 ESR 计算上游跌落包络在首窗口内的传递，叠加本地负载跌落，核对电压余量。结果保留来源链。它不能证明周期稳态、长期恢复、高频阻抗或环路稳定性；频率和抗干扰指标缺失时不能唯一确定串阻、旁路值或电容只数。

不支持：恒流驱动、多个驱动器分担同一负载、多级晶体管通路、未知电流转移拓扑、级联滤波与完整时域仿真。发现不适用路径会阻止套用本模型，不能用手填总电流绕过。此版本有合成拓扑测试和显示板实跑证据，尚未覆盖多种真实产品。
