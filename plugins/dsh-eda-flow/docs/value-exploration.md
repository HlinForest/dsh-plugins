# 阻容备选的同条件复算

第三步先恢复或提交当前候选，再调用 `design_explore_values`。每组仅提供已有阻容的位号和值，可以同时改变同一供电域内多只电容的值。宿主保持网络、负载、时间、电压预算、容量折减和 ESR 不变，重新运行联立供电、储能、电流及来源约束计算。

结果列出实际冲突、条件范围及缺失的目标。上拉没有输入电容和上升时间时，只有灌电流约束带来的下界；显示负载没有亮度/平均电流目标时，不能从电流上限推出唯一阻值。储能给出的总容量下限不能确定电容的只数、各值或高频表现。替代组合沿用原 ESR 和容量折减条件只是对照计算，不能证明其实际器件性能。

探索不会修改候选，也不会提供完成凭证。模型采纳备选时须通过 `design_amend` 改变实际器件与设计依据，或通过 `design_review` 提交含新增/删除器件的完整候选。随后仍执行来源、用途、接线和工作点审查。不能修改工作条件来让某个目标阻值通过，不能输入参考工程参数作为设计约束。

此能力支持有工作点覆盖的通用 Device:R/Device:C 已装配器件，最多八组、每组十二个取值。尚不进行自动采购选型、容差最坏情况分析、阻抗频谱仿真或自动改变器件数量。
