# 供电联合计算与储能评估

从 0.13.11 起，已建立有效单级 RC 和上拉工作点时，宿主会保持器件值、负载条件及其他支路不变，比较该上拉接滤波后或上游的两种电路。比较项包括接收器最低供电、该输出切换引起的供电变化、稳态灌电流与切换电流条件上界。共享电源上的其他负载仍保留；不支持或数据不完整的电源域不输出可用比较。

从 0.13.12 起，结果中的 `biasRailComparisons[].policy` 直接约束候选接法。选择顺序为：当前器件资料中可可靠识别的明确接法/上拉电压要求 → 同一组工作条件的直流限值 → 可行方案中的明确资料建议 → 最小化本输出切换引起的滤波电源名义电压变化。最后一项是公开的工程目标，不是厂家要求，也不证明其他电源噪声或整体 EMC 更好。条件改变后必须重新求解，不能为了保留原接法随意放宽假设。

资料限制从当前器件事实所引用的单器件文档读取，保留文档、页码和原文。当前自动识别范围限于明确的中英文连接要求/建议以及输出上拉电压不得超过的数值。带条件的条款、多器件范围不明、否定句、未限定的 VCC 或冲突条款不会被猜成接法：这类明确但不能识别的指令阻止自动选择。图中接点、复杂表格额定和时序规则仍需后续提取能力。未识别到限制不代表器件没有限制，额定适用性、输出耐压、断电容限和输入阈值保持待核实。

模型在 `peripheralAssessments[].output.railDecision` 提交 `{connection,basis:{kind:"calculated-policy",policyId},unresolved:[]}`。`connection` 必须属于本次返回的 `acceptedConnections` 且与实际网络吻合，旧版本自由文字 `reason` 不再用作选择依据；理由由宿主根据计算和引用生成。更有说服力的文字不能授权较差或不合规的候选。适用资料明确要求本地、或上游违反明确电压限制时，可接受接法会是本地；规则没有固定上游答案。

每个比较案例返回由现有实际端点推导的 `pinMoves`。模型用 `design_amend` 修改候选，更新相关外围说明和储能负载范围，然后完整重新审查。没有仅修改说明的捷径，也不改变已冻结的 CAD。此流程不需要用户补逐脚连线或器件坐标。

该比较只在明示条件下成立：高态按开路、上游按理想源、负载按已声明恒流近似；尚未证明输出耐压、断电容限、接收端电平、源阻抗及动态响应。`nominalDcWithinDeclaredLimits` 只表示这一名义直流比较满足已声明的电压和电流条件，不代表适用规格或硬件通过。现有工作点的引用与假设逐项附在比较结果中，不按 AD 的接点或数值作选择。

从 0.12.0 起，设计评审按候选的实际网络连接计算滤波供电与上拉负载。外部输入仍是文字需求和独立规格书，用户无需提交完整逐脚连线或器件坐标。

## 供电和输出必须一起计算

接在滤波后电源的上拉电阻会在输出低电平时消耗电流。宿主将接在同一滤波电源上的器件自身电流、全部上拉支路联立计算。所有输出低电平时检查最低供电；本输出低电平、其他输出高电平时检查该输出最大灌电流。零欧连接仅在分析中合并，原设计网络不改写。

模型提交 `rc-filter` 和 `pull-up` 工作条件；同一滤波器的 `supplyVoltage` 都指上游源电压。器件自身 `deviceCurrent` 不重复包含外部上拉电流。遗漏负载、重复计数、电源条件矛盾和未支持的级联路径都会给出错误，不能退回独立公式假装通过。滤波后上拉的上升时间涉及两个电容节点，当前不会用独立 R×C 公式签核时序。

## 储能与高频旁路分别评估

每个已声明本地去耦归属的供电域需要一条 `supply-transient` 工作点。模型给出实际电源域的增量负载、支撑时间、允许压降、有效容量比例和整个电容组的等效串联电阻；宿主检查候选中真实并联电容，计算：

ΔV = ΔI × ESR + ΔI × Δt / C有效。

这是假定电容在明确时间窗口内独自支撑增量负载的电荷预算。它不能证明高频阻抗、供电环路稳定性或实物瞬态响应，也不决定必须使用几只电容。不能为通过审查随意降低负载、缩短时间或放宽压降。资料没有给出的条件必须显示为工程假设，保留核验事项。

从 0.13.0 起，储能评估按实际网络自动加入本电源直接供电的外部上拉切换负载。有这些上拉时，工作点需声明 `loadStepScope: "excluding-pull-ups"`：`loadStepCurrent` 是排除这些已独立建模外部上拉后的基础增量。仅当本域没有已推导扫描或内部偏置时使用该范围。当前版本若已按实际网络推导扫描支路或内部偏置，必须使用 `excluding-derived-loads`，这些电流由宿主另加，不得再写入剩余增量。下游电源和其他未独立建模负载仍须包含在剩余增量中；接在其他电源的外部上拉不计入本电容域。旧数据未声明范围时会要求重评，不会静默选择相加或忽略。

切换电流的条件上界按声明源电压除以实际并联等效阻值计算。条件是上拉电源不超过该源电压、输出不低于返回端 0V；不能扣除规格书的 VOL 最大值来声称最大电流，也不能用转换后的低电源稳态电流代替初始切换电流。源过冲、预充和负向尖峰不在此模型内。这些假设显示在评估结果和待核实项中。

同一电源域的多个储能评估必须使用一致的基础增量、支撑时间、容量折减和等效 ESR。宿主除了检查压降预算，还会检查滤波负载的最低工作电压；同域上拉漏建模或重复建模都会阻止此项通过。

当前引用核验只能证明数值和单位确实出现在所引原文中。典型值、保证范围、绝对最大额定及其测试条件的语义尚未自动核实；涉及器件电流、电压和负载额定的引用会保留“数值已核对、额定条件待核实”，不能因为找到同一个数字就作为厂家保证。

该模型的设计依据是电荷守恒；将储能、ESR、高频旁路和系统瞬态要求分开核验，也与 TI 的 [Input and Output Capacitor Selection](https://www.ti.com/lit/an/slta055/slta055.pdf) 中选型讨论一致。TI 的 [SLVA874](https://www.ti.com/lit/an/slva874/slva874.pdf) 进一步区分瞬态、纹波和稳定性约束。这里只采用通用物理检查思路，未导入它们的示例器件值或某种稳压器专用公式。

## 真实流程

上传规格书并确认提取结果 → 模型提出电路及工作点 → 宿主审查引用、实际端点、供电联合负载与储能 → 模型依据错误调整 → 人工确认后冻结 → 通用布局 → 原生网络与独立参考比较。

升级后恢复同一项目旧候选时，新增检查可能拒绝旧方案。恢复工具会返回该项目原模型候选及具体错误，模型修改后必须重新完整评审。旧候选的历史成功不能代替当前检查；ERC 通过也不能代替 AD 的器件、参数、网络和图面比较。
