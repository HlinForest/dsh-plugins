# PDF 正文与表格

PDF 仍作为独立附件上传，插件不内置某块板的规格书或参考网表。每页正文保持原文和页码；有清晰表格线的表格会额外生成可引用的行列记录，并保存原单元格及原页位置用于核对。

当表格明确给出“单位”列，且数值列明确标为最小、典型、最大、数值或范围，单个数字可以继承该行单位。例如 `Typ=18` 与 `Unit=mA` 展开为 `Typ=18 mA`。只有受支持的单一电气单位采用这种展开；混合单位、空白格、含糊表头和范围表达不猜测。原页正文不被替换。

这是行列关系与单位的机械整理，不是厂家额定语义的自动批准。提取应用事实时须同时保留参数名、列名、测试条件与文档版本。测试条件中的端电压不能直接当成固定驱动压降；极限额定不能直接当成正常工作条件。工作点评估仍保留额定条件待核实标记。

当前表格识别依赖 PyMuPDF 的有线表格提取。扫描图、无表格线的复杂布局、多层或跨页表头尚不保证覆盖；原始页面正文和提取警告保留。图片中应用电路的数值不会因页面存在其他文字就自动读懂，必须从已核对的可读正文或相应图面证据补充。必要的资料补页应作为可见外置 PDF 提供，不能写进插件电路模板。

资料提取完成前，宿主检查原文中可识别的阻容数值是否进入带引用的应用事实。检查同时要求事实陈述包含相应数值，单纯引用整页却只写“应去耦”不能覆盖原文的具体电容组合。相同页面的正文和表格记录不重复计数；其他文档的相同数值不能代替当前引用。该检查只覆盖明确阻容数值及来源，不宣称所有应用语义、图中连接或额定条件均已理解。设计阶段可以选择其他组合并说明理由，提取阶段必须先保留资料事实。

物理尺寸覆盖也将同页正文与表格视为同一来源：仅在文件哈希、页码及原始表格行对应时，表格引用可覆盖正文中的尺寸。不同文件、不同页或其他行里的相同数字不互相覆盖；表格中没有正文对应的尺寸仍须保留。此项不批准完整封装，也不生成原理图固定坐标。

资料中的独立 `*` 或 `?` 位号表示未分配，归档时保留原标记，设计时由模型分配有效位号。已保存的旧事实在使用时采用相同解释，不改写原始记录；引脚、型号、引用和真正已指定的位号保持约束。
