========== 01_任务书.txt ==========
显示板原理图：文字需求驱动的真实 MCP 生成演示，输入版本 1

交付目标
从空白工程建立一张可编辑的 KiCad A4 横向原理图，重建显示板接口、红外接收、TM1616 驱动、共阴显示器和原工艺标记。此次仅生成原理图、符号库、BOM、PDF及核验记录，不做 PCB。
全部工程事实以这份公开文字输入和附带规格书正文为依据。页面上每个对象的位置属于工程师指定需求。不得将几何准确执行说成模型自行推导了原版面。

功能与必须保留的要求
主板提供 +5V 和 SGND，以及 DIN、CLK、STB 三路控制信号；红外接收输出 RCV 返回主板。
DISP 连接器 1=RCV、2=SGND、3=+5V、4=STB、5=CLK、6=DIN，针号不能倒序。
U1 型号 TM1616，D1 型号 IRM-3638M3-X。保持原显示符号位号为 *、值为 LED；型号没有证据时不替换成其他显示器。
U1 的 SEG1、SEG2、SEG3、SEG4、SEG5、SEG6、SEG7 经对应电阻接显示段 C、E、G、D、F、A、B。
GRID1、GRID2、GRID3 分别接显示器脚1、3、2；GRID4脚12明确不连接。
各原器件值、原始物料参数、原封装名称、1/2脚对应和所有跨线电阻均保持文字清单要求。C2=1uF/0603，C4/C8=4.7uF/16V，均为非极性贴片电容，不改成电解。
R1=220R/0805 是红外电源串联电阻，R3=22K/0805 是RCV上拉；七条段线对应电阻均47Ω，封装按逐件清单。

输入阅读规则
01_任务书.txt 是流程与验收要求；02_器件引脚与属性.txt 描述每个器件、脚号、网络和属性；03_符号图形.txt 是各符号局部图形规范；04_页面连线与标注.txt 是页面对象；05_规格书依据.txt 说明资料边界。所有文件是可粘贴正文。人类可阅读的表述由模型转换为 MCP 参数，不能把它们交给预制任务书解析器直接输出 CAD。
缺失或冲突的关键要求通过文字提问。这里已明确的要求不重复征求确认。其余实现细节可自行决定并记录依据。

坐标和外观
页面 X 向右、Y 向下，单位mm，A4横向。所有坐标小数保留至少6位；无自动网格吸附。
源到页面的固定换算为 X=0.254×源X，Y=209.55−0.254×源Y。本输入已经转换好，不要再次换算。
符号图形及针脚采用局部 X 向右、Y 向上；放置实例旋转为0，原旋转已经体现在局部图形中。
引脚角度按KiCad约定：0朝右、90朝上、180朝左、270朝下，描述从连接端点指向符号内部的方向。
引脚名称与脚号字号均1.27mm，名称内侧偏移0.762mm，可见性逐脚按表。
页面角度、属性可见性以各行说明为准，保留源文字和标签的完整0/90/180/270方向。中文字体用SimSun，英文亦可使用SimSun；不同软件字体渲染差异不改变坐标验收。
源电源端口映射为同名KiCad局部网络标签，保留其锚点与方向。此映射不宣称AD电源端口内置图形像素相同；源Style在文字行中保留供核验。没有原AD页面PDF，不能宣称已核对原软件最终渲染。
颜色跟随KiCad主题；实心符号底色使用background。源圆角矩形需保留rx/ry，以不超过0.0005mm的弦误差表达曲线；不得把所有圆角一律改成圆弧。

属性与装配
Value等于源Comment；Reference保留原位号（包括 * 和带空格位号）。其余属性保留原始名称和字符串。
添加隐藏字段 OriginalFootprint=原封装名称、OriginalLibrary=原库标识、SourceRecord=资料记录号；源描述型号为原参数，不擅自替换。
本轮Footprint可保持空值，由OriginalFootprint保存原封装标识；这是未建立PCB封装几何的明确边界，不将没有几何的库标成可制造。
各实例in_bom=true，dnp=false。仅 QR Code 的on_board=false，其他on_board=true；无引脚的工艺图形仍保留原对象，在采购BOM中独立标记为工艺对象而非电子元件。

电气检查
U1脚1/2/3为input，4/14为power_in，5至13、15/16为output；GRID4仍标NC。D1脚1为output，2/3为power_in。
DISP是主板边界接口：2/3作为外部供电源power_out，4/5/6作为主板输出output，1作为主板输入input；此为接口电气角色，非物理连接器主动供电声明。
其余电阻、电容、显示器引脚为passive。原始无源类型不作为新图正确性的依据。
先运行真实ERC，必要的辅助供电声明需单列为非物料检查对象，不能改变物理连接或遮盖其他错误；不可通过全局关闭检查或把电源输入改成无源清零。

执行和证据
通过MCP建立/修改CAD；可以用客户端发送模型自行组织的MCP参数，不能运行历史转换器或直接写CAD格式文件。
按任务与约束、资料、器件、原理图、BOM、PCB未执行、核验交付记录实际状态。
每次调用保留工具名、参数、返回和文件哈希；生成器不读取旧工程。首次完成后冻结输出，交回主任务独立核对，再根据公开差异和文字补充修正。
验收：41原始对象、29电气器件、85原始电气引脚、24连接网络及1个NC分组。辅助ERC对象单列且从物理BOM排除。
每个物理引脚连接、原参数和原始封装标识匹配；实例/引脚/文字/线段/连接点/NC及符号图形坐标误差≤0.001mm。允许UUID、工程名与生成时间变化。
保留特殊位号 * 引起的编号提示，不自动更名。制造、固件联调和实物性能未验证。

一、概述
TM1616是一种LED（发光二极管）驱动控制专用IC,内部集成有MCU数字接口、数据锁存器、LED
驱动。本产品质量可靠、稳定性好、抗干扰能力强。主要适用于家电设备(智能热水器、微波炉、
洗衣机、空调、电磁炉)、机顶盒、电子称、智能电表等数码管或LED显示设备。
二、特性说明
• 采用CMOS工艺
• 辉度调节电路（8 级占空比可调）
• 显示模式（7段×4位）
• 串行接口（CLK,STB,DIN）
• 振荡方式：内置RC振荡
• 内置上电复位电路
• 内置数据锁存电路
• 内置针对LED反偏漏电导致暗亮问题优化电路
• 抗干扰能力强
• 封装形式：SOP16、DIP16

九、应用时串行数据的传输：
（1）地址增加模式
使用地址自动加1模式,设置地址实际上是设置传送的数据流存放的起始地址。起始地址命令字发送完毕,
“STB”不需要置高紧跟着传数据,最多7BYTE,数据传送完毕才将“STB”置高。
Command1: 设置显示模式
Command2: 设置数据命令
Command3: 设置显示地址
Data1～n: 传输显示数据至Command3地址和后面的地址内（最多7bytes）
Command4: 显示控制命令
（2）固定地址模式
使用固定地址模式,设置地址其实际上是设置需要传送的1BYTE数据存放的地址。地址发送完毕,“STB”不
需要置高,紧跟着传1BYTE数据,数据传送完毕才将“STB”置高。然后重新设置第2个数据需要存放的地址,最多
4BYTE数据传送完毕,“STB”置高。
Command1: 设置显示模式
Command2: 设置数据命令
Command3: 设置显示地址1
Data1: 传输显示数据1至Command3地址内
Command4: 设置显示地址2
Data2: 传输显示数据2至Command4地址内
Command5: 显示控制命令

问题 2：真实 ERC 报 D1 的 VCC 引脚没有 power_out 驱动，如何处理？
回答：D1 由主板 +5V 经 R1（220R）供电。保留此物理连接，按任务书已授权的辅助供电声明规则，允许在 R1 后、D1 VCC 所在现有网络添加一个纯 ERC 声明对象。位号以 #ERC 或 #PWR 开头，属性 Role=ERCHelper，in_bom=false、on_board=false；仅包含一个 power_out 引脚，不增加物理物料。辅助对象单列，不改变原有 41 个对象和 85 个引脚的验收范围。不得修改 D1 电源输入类型或关闭检查以消除错误。

问题 3：显示器位号 * 的第 5 脚不在 KiCad 默认连接网格上，是否移动？
