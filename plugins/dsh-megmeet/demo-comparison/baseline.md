## 3. 优先候选与排除原因

### 3.1 优先候选（第一顺位）

**DEMO-PS-A（虚构演示电源 A）** — 唯一"通过已列条件"的型号。
- 通过依据：输入 AC / 180–264V / 输出 48V / 3000W / 效率 96.5% / -20–60℃ / CAN+RS485 / CE+UL / fan，九项与需求逐项一致或覆盖。
- 需注意的工程边界（不改变上述结论，但必须由工程师确认）：
  1. 输出功率 3000W **恰等于**需求下限，无余量，需确认是否为额定连续输出能力；
  2. **温度降额未验证**：-20–60℃ 是否为全温区满功率，高温端是否降额，资料未说明；
  3. CE/UL 的具体标准与适用范围未提供。

### 3.2 次选（备选，必须先闭合资料缺口）

**DEMO-PS-C（虚构演示电源 C）** — 功率余量更大（3300W）、温度范围更宽（-30–70℃），输入电压与协议/认证均满足；**唯一缺口是效率资料未提供**。在取得该型号效率数据并确认其 ≥96%（同时确认温度降额）之前，**不得按"满足"处理**。

### 3.3 排除原因

| 型号 | 排除结论 | 排除原因（逐条） |
|---|---|---|
| DEMO-PS-B | 硬性不匹配，排除 | 输出功率 1500W 低于 3000W 下限，属硬性指标缺口，无法通过配置或其他满足项弥补 |
| DEMO-PS-D | 硬性不匹配，排除 | 输入电压 200–240V：下限 200V 高于要求的 180V，上限 240V 低于要求的 264V，**未完整覆盖**客户 180–264V 全范围；区间相交不等于覆盖。即使其功率(3500W)、效率(97%)、温度、协议、认证均满足，仍因输入电压条件不满足而排除 |
| DEMO-PS-E | 硬性不匹配，排除 | 三点硬性缺口：①输出电压 24V ≠ 48V；②通信协议仅有 CAN，缺少 RS485；③认证仅有 CE，缺少 UL |

> 补充说明：DEMO-PS-D 若客户愿意把输入电压需求放宽到 200–240V，可在书面变更需求后重新评审，但在当前需求原文下**不通过**。
