# 演示页设计

用途：在演示中并排阅读同一 prompt 的两次真实 DSH 输出，并查看参数校验的原始证据。

配色：纸白 #FAFBFE、工程蓝 #163557、链接蓝 #315E9B、通过绿 #006B61、正文灰 #566474、分隔线 #D3DBE6。不使用公司官方标识，不把虚构产品包装为真实型号。

字体：中文使用系统 Microsoft YaHei UI，正文搭配 Segoe UI；报告标题与表格靠字重、字号区分层级。

布局：顶部简短说明真实结论，正文直接展示左右两份报告。切换“逐项校验”“共同输入”“演示说明”可以逐步展开证据。宽屏并排，窄屏纵向。全部文字左对齐。

```
同一份需求，两个运行结果
分类一致；插件带来可核查的校验记录
[原始输出] [逐项校验] [共同输入] [演示说明]
无插件报告                 已安装插件报告
```

复核：避免把 token 与时间数字做成营销指标；不使用装饰卡片、渐变或自动动画。演示的重点是两份真实报告与工具证据，布局应直接服务阅读。保留本次结论一致、插件 token 增加、单次运行不能推断整体准确率或速度的说明。
