## 三、CRSC-DUAL（24V/20A 与 12V/6A 双路同时输出）

**结论：双路同时输出这一硬性初筛字段，通过 0 个型号；本资料库无任何双路输出产品，故本条不存在可初筛候选。**

全库 28 个型号的 `output_channels` 均为 `1`（原文"单组输出"）：24V 型号 8 个、12V 型号 7 个，但**没有 24V 与 12V 同时输出的型号**。按采购 scope"单路不能宣称满足"，单路型号无论如何都不能替代双路条款。参考性推算（由 P=U·I 得到，**非原文额定电流**）：MPT150-24V ≈ 6.5A、MPT210-24V ≈ 8.8A、MPT350-24V-F ≈ 14.6A、MPT600-24V = 25A，均无法覆盖 24V/20A（480W）与 12V/6A（72W）**同时**输出的组合。

**排除示例（≤3）**
1. **MPT600-24V**：单路 24V/600W，无 12V 第二路；输入 180–264Vac 不覆盖 176–179V；散热归属未证；效率 Typ.85% 非保证下限。
2. **MPT350-24V-F**：单路、**风扇散热与"自然冷却"不符**；输入高端档缺 176–179V；24V 支路功率 350.4W < 20A 对应需求。
3. **MPT75-12V**：72.0W 恰好等于 12V×6A，但为单路输出，**仅可能覆盖 12V 支路，不能代表双路同时输出**。（MPT210-12V、MPT350-12V-F 同类，按单路批量排除。）

**关键差异与缺失证据**：效率 ≥85%、输入频率 47–53Hz、自然冷却、功率因数 ≥0.9、输入 THD、纹波、续流（保持）时间、均流冗余与保护阈值，均**无对应字段/原文数值**，属资料缺失；效率仅有 Typ. 值（如 MPT350-24V-F Typ.86.5%、MPT600-24V Typ.85%），**不能当作保证下限**；频率不可由 `90~132Vac/180~264Vac` 反推。双路型号与均流冗余证据须另取厂家资料。
