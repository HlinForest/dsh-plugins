# 真实物料与公开需求演示

打开 `index.html`。页面包含 6 条确定性测试、原始模型对照、28 个真实型号、可点击规格书和实际 DSH 聊天点击截图。

## 已保存的内容

- `materials/`：8 份麦格米特工业电源官方使用指导书，覆盖28个型号；另有3份医疗电源目录。下载清单保存官方入口、文件哈希和采集日期。PDF 为扫描件，工业选型表已逐份视觉核对。
- `requirements/`：4个官方出处的原文快照和研究记录。包括北航、中国通号、黄河水利职业技术学院，以及广州院校的政府采购成交结果。历史文件不代表正在采购。
- `test-cases.json`：6条整理后的测试输入。原文、算术换算和派生拆分分别标明。广州成交120W保留等值筛查，没有自行改成最低功率。
- `catalog.real.json`：管理员配置的28型号产品库，限定交流工况。双段输入不合并，Typ.效率不作保证下限，含降额温度不作无条件满功率范围。
- `deterministic-results.json` / `reports/`：每条输入的基础初筛和完整条件校验，共336次型号评估。
- `baseline.md` / `plugin.md` / `prompt.txt` / `runs/`：本轮v0.1.3对照。两组同Prompt、模型、资料和工作目录；配置差异仅为插件。原始回答未修改，运行证据未导出凭据。
- `round1-v0.1.2/`：首次真实测试原始记录。它暴露了单路/双路校验不足，因此补充了输出路数硬条件，随后重新运行公平对照。两轮Prompt因增加双方均可见的路数参数而不同，不能直接把两轮看成同一个实验。
- `native-chat-*.png` / `native-chat-link-verification.json`：DSH rc.2原生网页聊天的点击验证。`native-chat-real-plugin.png` 来自真实调用v0.1.3插件后点击MPT150资料版本，原版工业PDF在右侧打开；文本链接可定位行号。没有保存浏览器登录状态。

## 已验证的关键结果

24V、至少120W、176–264VAC的基础初筛通过MPT150-24V；48V对应MPT150-48V。完整冗余、报警和保护等条件仍待确认。24V、至少240W的这批型号没有同时通过功率和输入覆盖；单组输出产品不能满足双路同时输出。所有结果仅适用于这批资料。

两组模型都识别了主要参数缺口。插件明确列出硬性排除并保留11次工具调用记录；普通模型也可能给出同样的判断。模型答案中的“候选”、计数和叙述应与确定性记录核对，不声称单次实验证明准确率或速度提升。

## 安装与复核

本机桌面profile已安装 `dsh-megmeet@0.1.3` 并配置此真实目录。重新加载/重新打开DeepSeek Harness后使用。`install-desktop.ps1` 可重复安装，旧配置备份保存在用户DSH私有目录。

聊天测试输入：

> 先调用megmeet_get_catalog_info。分析输入电压176–264VAC、输出电压24VDC、额定功率至少120W，要求1+1并联冗余。生成报告，保留资料版本原件链接与待确认条件。

更新公开库或文件位置后重新加载插件。复制演示文件夹到另一台电脑时，重新运行安装脚本，使catalogPath指向新位置；网页使用相对原件链接，原始模型回答保留当时的绝对路径。

运行无需模型的验证：

```powershell
node scripts/verify.mjs
```

`scripts/prepare.mjs` 会重新生成目录和Prompt，因此不要在历史证据目录上随意执行。模型对照重新运行时应创建新输出目录，不覆盖本次原始记录。大型工具返回会被DSH预览截断，完整原始结果已从官方临时spill文件恢复并保存于 `runs/tool-spills/`。

模型运行脚本依赖项目的 `.verification/dsh-host` DSH rc.2测试运行时、Node 22.19以上和 `npm ci` 安装的项目依赖；资料包不包含运行时和账户配置。离线页面、PDF和原始证据可直接查看。`scripts/package-demo.py` 生成资料包与插件源码包，`artifact-manifest.json` 保存逐文件SHA-256供复核。
