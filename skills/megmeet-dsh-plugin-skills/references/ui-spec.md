# Megmeet DSH Plugin UI Spec

版本：2026-10-14。范围：本项目的 DSH 插件视觉与窗口约定，不代表企业发布的设计标准。

实际渲染参考：[标题栏与页面顶栏](window-header.png)、[宿主图标入口](host-entry.png)。按当前实现和上述版本阅读，不把截图中的具体项目名当作固定文案。

## 设计依据与边界

以用户提供的 Harness 截图及本机计算样式为视觉依据。沿用 IBM 风格的信息层级、表格与步骤组织，外观采用 Harness 的浅灰框架、白色工作区、圆角与轻分隔。用户只要求优化外观时，保持已确认的栏位、页签、字段、操作和流程顺序。

独立业务窗口使用插件自己的身份与图标。不要复制 Harness 的品牌标志冒充宿主，不在产品页面放开发过程、实现细节或泛化防御声明。实际缺项、错误与来源放在相应数据或执行结果中。

## 宿主入口

| 属性 | 约定 |
| --- | --- |
| 位置 | 使用宿主提供的插件入口槽位；不修改其他插件的布局或样式 |
| 形态 | 紧凑单图标按钮；不把“电路设计”等短标签压成多行 |
| 尺寸 | 40 × 40 CSS px 点击区域，20 × 20 图标，8px 圆角；与邻居留至少 8px 间距 |
| 外观 | 默认透明，图标继承正文颜色；悬停底色 `rgba(38,49,72,.06)` |
| 解释 | 悬停及键盘焦点显示名称；按钮有独立可访问名称，图形本身不重复朗读 |
| 加载 | 保持按钮尺寸，换成忙碌图标并防止重复提交；不用长加载文字挤压邻居 |
| 失败 | 显示可读取的原因并可重试，错误提示不参与底部横排宽度计算 |
| 行为 | 点击打开独立窗口；再次点击激活原实例，最小化时恢复；不新建业务项目 |

电路设计使用与窗口内品牌一致的 Carbon FlowConnection 轮廓。其他插件选择语义对应的同风格图标。

## 窗口外壳

| 属性 | 数值或行为 |
| --- | --- |
| 初始大小 | 1280 × 850 逻辑像素；Windows DPI 缩放后物理截图可能约为两倍 |
| 最小大小 | 当前实现 640 × 520；内部响应式行为见下文 |
| 标题栏 | 40 CSS px 高度，背景 `#f9fafb`，文字与系统按钮 `#61666b` |
| 标题 | `项目名 · 电路设计`；项目名最多显示 40 个字符，溢出省略 |
| 标题图标 | 16px，文字 13px，图标间距 8px，水平内边距 16px |
| 页面顶栏 | 同样 `#f9fafb`，不在标题栏下叠加深灰带、厚边框或阴影 |
| 系统交互 | 保留原生最小化、最大化／还原、关闭；空白标题区域可拖动 |

当前实现使用独立 Electron 运行时：`titleBarStyle: hidden` 和 `titleBarOverlay: { color: '#f9fafb', symbolColor: '#61666b', height: 40 }`。页面预留 40px 标题栏，拖动区域使用 `app-region: drag`，标题文本通过 Window Controls Overlay 的安全区域避让系统按钮。网页模式不额外渲染桌面标题栏。

Edge 应用窗口的自绘灰色标题栏不能只靠网页 `theme-color` 消除。保留 Edge 回退可以提高可用性，但该回退不计为标题栏一致性验收通过。

独立窗口使用自己的进程与用户数据目录。渲染页不开放 Node；preload 仅暴露必要的呈现信息。宿主只承担入口与原有后端服务，聊天区域可继续输入、切换会话，关闭插件窗口不关闭 Harness。模型选择与凭据仍由 Harness 管理。

## 视觉变量

| 项目 | 数值 |
| --- | --- |
| 框架／标题栏／侧栏 | `#f9fafb` |
| 工作区／AI 栏 | `#ffffff` |
| 正文 | `#0f1115` |
| 辅助文字 | `#61666b` |
| 占位文字 | `#a6abb2` |
| 主要操作／链接／焦点 | `#4176e6`；主要按钮悬停 `#356bd6` |
| 普通分隔 | 1px `rgba(0,0,0,.08)`；栏间分隔可用 `.06` |
| 输入边框 | 1px `rgba(0,0,0,.12)`；悬停 `.22` |
| 侧栏选中／图标悬停 | `rgba(38,49,72,.06)`；不再加粗蓝色左边线 |
| 圆角 | 图标按钮 8px；控件和导航项 12px；表格、预览和菜单 16px；弹窗 20px；助手输入框 28px |
| 阴影 | 主要用于弹窗、菜单及助手输入框；避免每个表格或分区都套浮起卡片 |
| 字体 | `-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', 'Helvetica Neue', Helvetica, Arial, sans-serif` |
| 正文字号 | 14px，行高 1.5 |
| 标题层级 | 页面 22px/600，分区 20px/600，小标题 16px/500 |
| 品牌 | 图标 24px，品牌文字 18px/600，间距 8px；不做大面积品牌横幅 |
| 动效 | 控件状态过渡 120ms，遵循减少动态效果偏好 |

蓝色集中用于动作与选中信息，状态采用少量语义颜色。表格保留信息密度，按区域划分而不是把每个字段都套成卡片。键盘焦点使用 2px 蓝色轮廓；禁用、执行中、失败、待更新状态可辨认。

## 三栏工程窗口

此布局用于已确认的工程流程。其他类型插件先保留自己的布局，再应用上述视觉规范。

| 区域 | 内容与几何 |
| --- | --- |
| 页面顶栏 | 品牌、项目切换、新建项目、当前模型；桌面 48px 高，不含 40px 窗口标题栏 |
| 左栏 | 步骤与状态、资料、操作记录；大窗口 240px |
| 中栏 | 当前步骤的表单、页签、数据、图纸；`minmax(0, 1fr)` 自适应 |
| 右栏 | 当前项目／当前步骤的 AI 助手；大窗口 392px |
| 底栏 | 上一步、保存、具体执行动作、确认继续；76px 高，占中栏与右栏 |

1440px 以下左／右栏为 208／320px；1200px 以下右栏由按钮展开；768px 以下左栏也折叠，页面顶栏为 56px、底栏为 112px。独立窗口实际最小宽度为 640px，390px 作为网页响应式检查尺寸。

中栏和右栏分别滚动；底部操作使用网格行保留空间。工作区顶左圆角 16px 与浅灰侧栏衔接。抽屉在桌面模式避让 40px 标题栏，避免把网页栏顶坐标直接当成窗口栏顶。表格可在自身容器内横向滚动，整个页面不应横向溢出。

## 验证与交付

- 用真实窗口截图比较标题栏和顶栏空白处的像素颜色；同时核对 CSS 尺寸与 Windows 缩放，不能只凭颜色变量声明完成。
- 宿主入口在普通、加载、失败状态下尺寸不变；悬停名称、键盘打开和重试有效，邻近插件可点。
- 原生窗口可拖动、最小化恢复、最大化还原、关闭重开；重复打开不增加窗口或项目。
- 视觉改动覆盖涉及的页面；布局改动才扩大检查范围。桌面 1280、宽屏 1586、窄窗 1000、网页 390 为有用的检查点。
- 默认本机仅模拟模型响应，不点击真实生成或发送模型消息。不要为颜色、圆角或入口修改重跑整个 PCB 生成链。
- 区分源码更新、构建结果、已安装插件和实际截图。安装需保留可恢复副本；不因此重启正在正常工作的宿主后台。
